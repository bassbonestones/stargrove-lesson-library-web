Companion facilitator 02 — Truthful information-gap report and original inquiry

Paired complete lesson: Lesson 02; separately uncounted objective educator guide.

Specific instructional mechanism

A child may genuinely ask a willing familiar adult a question the child doesn't know and the adult actually knows, OR tell a real willing listener a truthful harmless fact not previously known to that listener when such a safe event occurs. A real two-direction knowledge gap needs one adult and child, not an extra staff member. Actual source-valid child language is possible even if the adult already knew the report; in that case don't claim new unshared fact transfer. For PK3 separate actual own need/want expression from neutral fact report, and for PK4 identify different authentic purpose types rather than rote phrase repetition. Fictional topics are legitimate for original child questions, but character scripts aren't child intent.

Adult preflight, real materials, genuine child agency

Set up broad safe accessible objects/books and a quiet optional exit. With a single caregiver, the child may sincerely ask a real question the adult actually knows the answer to, offering a genuine child-unknown/adult-known information gap. A truly unwitnessed harmless shape change is another optional report context only when child can safely make it and one caregiver maintains adequate supervision while briefly looking away; never blindfold, physically abandon or invent adult ignorance. Extra willing adults/class peers are optional, never required. A child's true original report when listener already knew the fact may be valid PK4 language, but don't falsely label it newly transferred information. Use distinct adult-owned model, no staged personal secrets, forced questioning, small hazards or hidden essential care.

ENTRY, MODEL, DURING, truly fresh independent EXIT and later REVISIT

ENTRY: first genuine child-authored own want/question/report in a safe activity to real willing adult, before adult teaching example; a true information gap exists if child sincerely asks what adult actually knows, or child truthfully tells an unwitnessed fact to a genuinely uninformed willing listener. MODEL: with one adult, narrate a different adult-owned report/question as explicit teacher example, any pretend reply labeled hypothetical; an optional second willing adult can genuinely model an unrelated fact exchange, never necessary. DURING: support original child wording/sign/AAC and distinguish real information novelty, recipient initially misunderstanding and actual successful exchange rather than infer from a prop. SOURCE: PK3 a real own basic want/need message may be a genuine statement (“I'm cold”) as well as request, not merely neutral report. PK4 different language purposes can emerge at separate real safe times, including an original question about fictional story. EXIT: optional changed safe object/real informed or uninformed context can provide a stronger mechanism/transfer check, but neither new prop nor a second human is a publisher prerequisite and an adult-supplied answer never qualifies as independent. REVISIT only on actual later calendar date, familiar safe scenario acceptable, NOT_OBSERVED before performed.

False-credit and misconception-specific correction

If the teacher already whispered the change to child and says “tell the listener,” it is teacher-origin H. If listener already saw change, no meaningful knowledge gap; use new genuine consented fact. PK3 only reporting observation without communicating an original actual want/need is preparatory, not PK3 source completion: include independent actual child-chosen need/want occasion rather than laundering the report as a need. Child-origin safe curiosity must not force question if child has none.

Mistaken-but-original report contingency: A child can independently communicate a genuine PK4 reporting purpose while making an ordinary factual memory error about a harmless object placement. Respond gently “Let's check together” and preserve the child's authentic language act; do not claim the factually incorrect message accurately informed a genuinely uninformed listener. A corrected message is independent only if child actually originates it, not by echoing adult's exact supplied correction. Source purpose, factual correctness and mutual understanding are different observations; don't manufacture a mistake to test the child.

Grade-specific source boundaries and honest original-language evidence

PK3.II.B.1: child genuinely independently uses expressive LANGUAGE to communicate a real own BASIC NEED or WANT, including chosen stored AAC, meaningful sign or home language to responsive real listener. Silent grasp, puppet answer, fabricated deprivation and adult-selected phrase cannot independently prove this source. Never withhold actual essential care or communication access. PK4.II.B.1: actual original language for MULTIPLE DISTINCT PURPOSES, such as genuinely different request, report, question, suggestion, explanation; not merely three identical requests, copied frames or speaker-selected icons. No fixed word count, sentence length or English-only voice criterion; source functions can be evidenced across appropriate genuine opportunities. Track child-original U, adult-written H, access-only A, uncertain origin X, true recipient, actual purpose and whether listener really responded. If no genuine need or relevant purpose arises, mark NOT_OBSERVED, no child deficit. Genuinely later calendar REVISIT only, no fabricated sessions.

Seven differentiated needs and written delivery modes

Attention/executive: authentic small optional choices, fade neutral picture reminders. Language/communication: learner-created purposeful home-language, sign, AAC including personally selected meaningful stored vocabulary; an adult cannot select semantic content. Literacy/phonology: no written words prerequisite. Numeracy: number of utterances never proves different purposes. Autism/sensory: voluntary low-stimulation context, no forced eye contact or communication performance. Developmental/intellectual: adult demonstration on different situation and increasingly original child requests/reports across grade. Motor/hearing/vision: stable accessible safe items and genuine neutral learner-directed proxy/qualified individualized access rather than preselected answer. SOLO — NOT IMPLEMENTED: virtual message button alone, especially preselected by an app, cannot prove real original communicative intent; no operational learner system. CO-PLAY: caregiver listens and responds to genuine child chosen meaning, essential needs served regardless of phrasing. ADULT-LED: adult-only model uses different props and words before unbiased new learner purpose. CLASSROOM: respect children's privacy, own individual messages and responsive willing listeners rather than choral recitation. Real child learning, independent educator and access expert approval, physical print validation, actual later REVISIT and four-mode educational parity NOT VERIFIED.

COMM-06 — Language-purpose examples are not an exclusive list: The printed PK4 outcome says language is used for multiple purposes, so a child may authentically greet/welcome, refuse or set a boundary, invite, comfort/reassure, joke, narrate a story, express gratitude or negotiate, as well as genuinely request, question, report, suggest or explain. Distinguish actually different pragmatic functions rather than awarding two just because they have different names: repeated requests are one kind, and “refuse”/“protest” may represent the same kind for a particular observation. Never force a social greeting, apology, comforting act or refusal as a staged performance; protect child consent, context and sign/home language/child-selected stored AAC. An authentic meaningful yet unforeseen purpose should be described for fair human judgment, not rejected simply because an example list did not name it. The synthetic evidence helper conservatively normalizes semantic aliases and flags emerging purpose classes for human adjudication instead of treating arbitrary unrecognized labels as child deficiency.

COMM55-05 cross-family score interpretation — clarification is not automatically a new purpose: For PK4, if child originally requests an item, then rephrases that same request after listener asks “which one?”, this may be valuable authentic clarification and improved mutual understanding, but is not automatically a second different language purpose. Labeling the second utterance `clarify` cannot manufacture purpose variety in the source helper: if that category is needed for PK4 source, it now returns pending contextual human adjudication unless a responsible observer can substantively establish a genuinely separate communicative purpose beyond additional request details. Another truly independent report, question, greeting, refusal, invitation, story or other genuine function can provide contrast. Do not coerce a repair or deny care, and do not treat all original clarifications as invalid language; the question is whether they show a distinct function.
