Objective-level educator guide — Child-authored communication needs and multiple purposes

PK3.II.B.1 — Child uses language to communicate basic needs and wants

Original published wording and source SHA-256 0063578a583acfe8cb1a4f6454615316564a8f1646525607bfbd4c285428e3ca. A child genuinely wants or needs something real, independently selects the meaning and uses LANGUAGE to convey it to a responsive actual human listener (speech, sign, personally intended home language or augmentative and alternative communication (AAC) including child-selected stored words). A gesture can complement language but silently grabbing a material without language-bearing communicative meaning is not automatically independent source. Water, toilet, food, medical/safety help, communication devices, quiet space and all fundamental access must NEVER be withheld to force a “need” request. An adult selecting “I want red” and child echoing it does NOT evidence original child communication, even when phonetics are perfect.

PK4.II.B.1 — Child uses language for multiple purposes

Published wording and SHA-256 701a1b3eee0e95ffa56e4e4a0fcd4558b56a564de7cd1275d6dbd31f8e69c274. Observe real learner-origin language serving DIFFERENT authentic functions, not just multiple utterances of the same request. Request, report an actually observed harmless fact, ask an honest information-seeking question, propose a creative plan, describe what happened or explain idea are plausible functions; do not invent a fixed compulsory count of exact functions, turn length or mode. The child may compose a meaningful selection using stored AAC vocabulary, and a picture/text card chosen by an adult without child message intent does not qualify. A relevant question that is really scripted by teacher is supported practice H, not child-origin evidence. Preserve functional meaning across home languages.

Three teaching mechanisms with individually complete lesson companions

  1. Lesson 01: real safe learner-origin self-advocacy + companion 01: child communicates a genuinely chosen safe need/want, then PK4 teaches separate uncoached reporting/question opportunities.
  2. Lesson 02: real harmless information gap (not yet in reviewed library) + companion 02 (not yet in reviewed library): child truly knows a harmless actual fact listener does not; sends real report and separately owns a genuine information-seeking question or proposal, not two copies of one request.
  3. Lesson 03: actual listener message repair (not yet in reviewed library) + companion 03 (not yet in reviewed library): child notices real benign misunderstanding and chooses how to restate original intended message, preserving basic need or multiple distinct functions rather than rote apology.

Honest developmental sequence and source evidence

See DEVELOPMENTAL_SEQUENCE.md: PK3 E3-1–E3-4 from natural wants to own help/stop needs, and PK4 E4-1–E4-5 extending meaningful purpose range with child control and independent new context. ENTRY first actual genuine child desire/purpose and real listener response, before teacher MODEL. Adult MODEL on separate unrelated adult-owned object demonstrates one purposeful request and another different informational report. DURING child creates real safe language meaning with a willing responsive listener while educators fade answer labels and literal scripts, never withhold safety or access. EXIT PK3 fresh actual harmless want/need delivered meaningfully by child to a real listener, no forced basic need; PK4 fresh naturally real authentic distinct functions with actual original child messages rather than repeated requests or copied teacher phrase. REVISIT truly later actual calendar date and changed benign real context; NOT_OBSERVED until real, no fabricated child data.

If learner merely echoes adult-written AAC “give me the red tile,” record H; later offer new neutral free choice and capture child-selected semantic message. If child selects stored “help” AAC at their own true intent, accept the genuine original meaning. If learner silently points but only gesture no language, distinguish supportive communicative behavior from claimed language without invalidating meaningful alternative language paths. If learner uses request then report, check report actually originated from personal observable event and isn't a copied script. If no need arises, count no negative result and do not deny water or resources.

Seven access profiles and delivery modes

Attention/executive: small genuine neutral choices and fade prompt cards; language/communication: meaningful child-origin home language, sign or AAC with personally selected true message; literacy/phonology: no printed conventional sentence or phonics prerequisite; numeracy: no counting utterances as proof of distinct functions; autism/sensory: quiet noncoercive choice and reliable alternative communication, never mandated eye contact; developmental/intellectual: adult examples on separate adult props then genuine child new purpose; physical/motor/hearing/vision: safe accessible large materials, neutral learner-directed proxy, individualized professional review for authentic intent/access. No deprivation or forced request for essential support. SOLO — NOT IMPLEMENTED: a software button could someday support real child-authored language, but adult/app preselected meaning is invalid; simulated listener alone cannot establish a real human response when that is the source condition. CO-PLAY: trusted adult listens to genuine child original need, not feeds target sentence. ADULT-LED: teacher uses different adult model and unbiased child EXIT. CLASSROOM: privacy-respecting real listener opportunities, no group chorus as individual language. External educator signoff, actual child learning, true later REVISIT, physical print/field accessibility and delivered four-mode parity remain NOT VERIFIED.
