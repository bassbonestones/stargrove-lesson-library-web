Classroom community roles — real child usefulness, assisted PK3 responsibility and varied PK4 functions

PK3: REAL meaningful classroom role with adult assistance permitted, supervision and support AVAILABLE; do not require fake adult prompting if child safely originates contribution. Role must serve a genuine class community, not decorative costume, adult-only work or purely own materials. Peers may use the class-ready result later; observed uptake is separate, stronger evidence. Adults handle safety, medical decisions, emergency, discipline and confidentiality.

PK4: Genuinely VARIED actual age-safe class responsibilities across real opportunities, on the same date or genuinely different dates; later dates are required only when claiming a delayed REVISIT. Repeated identical signs, costume labels, arbitrary new locations or forced public leadership do not show variety. A minimum two distinct authentic functions is a synthetic sanity check for plurality, not an official assessment quota. Adult help/access support permitted. Classroom benefit and child-owned role required, immediate witnessed peer use not universal cutoff.

Safety and access: Use only safe teacher-authorized accurate nonprivate group resources. No students' names, attendance, injuries, medical, behavioral, family or confidential record details, unsafe cleaning, heavy equipment, supervising peers or enforcing rules. Provide home-language, sign/AAC, large high-contrast/tactile accessible visuals, child-directed motor proxy, sensory quiet, choice to opt out and individualized IFSP/IEP/504. Adults check actual group information and retain all classroom supervision. Never grade a child's unwillingness as a deficit, require forced labor or invent evidence of actual recipient use.

Phases: ENTRY invite and observe actual first willing child role (including an age-safe assigned group-serving duty with adult-written true content); MODEL a different teacher-owned safe example; DURING real age-appropriate supported child-performed contribution; EXIT document the role already genuinely performed and separately optional additional new pupil-origin information only on another naturally authentic need (otherwise extra check NOT_OBSERVED). Same familiar location/activity remains valid for the real source role, with actual classmates who could benefit. Changed context is optional stronger transfer, not required. REVISIT only genuinely later observed calendar day; not automatically observed from a plan. A ready class-use cue can precede observed peer uptake. No helper badge/source inference from adult-only work.

PK3 four responsive stages — adult-assisted community contributions

PK3 C3-1 — Make a supported safe classroom-use choice

ENTRY: In a real class with an actually useful cue, child first chooses whether to contribute. MODEL: SAME teacher models separate adult-owned note. DURING: With age-appropriate help child chooses accurate accessible cue. EXIT: A meaningful new child-owned contribution for real classmates in familiar or changed activity; immediate observed peer use is optional stronger evidence. REVISIT: Actual witnessed later date, same context permitted, not automatically completed.

PK3 C3-2 — Help a real class understand a safe activity

ENTRY: Child may opt into teacher-approved broad cue/message role with actual class audience. MODEL: Adult models different nonprivate sign, not child's message. DURING: Learner meaningfully selects/signs/points at genuine helpful class activity message; adult supports access. EXIT: Actual child-owned class-ready cue, not pretend badge; peer use stronger observation if witnessed. REVISIT: Real later-date new group use, NOT_OBSERVED.

PK3 C3-3 — Contribute to shared community plan while supported

ENTRY: Invite a willing child to a true class choice need, including an assigned teacher-written safe group-message duty, and observe what the pupil actually does. MODEL: Same teacher models a different harmless adult-owned task, not a second colleague or child answer. DURING: Child meaningfully performs safe real group role with adult assistance; stronger child-origin true choice representation can be separately observed. EXIT: A real pupil-performed class role already completed remains valid without a second message; an extra genuinely new independent informational choice is optional only for another natural useful need, else NOT_OBSERVED. Actual peer consultation is separate. REVISIT: Only an actually later date with a new real child-performed act, NOT_OBSERVED beforehand.

PK3 C3-4 — Carry supported safe classroom responsibility forward

ENTRY: Teacher offers real safe class community role with child choice/access. MODEL: Same teacher demonstrates unrelated adult-owned task. DURING: Learner contributes safe class-benefiting choice, adult help/supervision available. EXIT: Real child-owned responsibility in genuine class, SAME familiar task valid, new activity optional transfer. REVISIT: Actually later day if witnessed; otherwise NOT_OBSERVED.

PK4 five responsive stages — different genuinely useful class roles

PK4 C4-1 — Take a meaningful actual classroom helper role

ENTRY: Child may choose actual class need and safe simple contribution. MODEL: Adult models unrelated teacher task to illustrate real effect. DURING: Learner chooses accurate useful classroom-use visual/message, responsible adults verify and aid access. EXIT: Real safe child-owned role serving genuine existing class community, familiar setting valid. REVISIT: Later true date different duty, NOT_OBSERVED.

PK4 C4-2 — Communicate accurate nonprivate shared class information

ENTRY: Child observes real community informational need, chooses whether to help. MODEL: Adult models safe different teacher-owned class message. DURING: Learner produces actual useful class picture/message with home language/sign/AAC, teacher verifies facts. EXIT: Authentic teacher-authorized useful shared class information, even about a familiar ongoing plan. A genuinely child-performed safe assigned duty conveying a teacher-authored true class message is a source-valid actual helper role, even though original pupil information authorship is NOT observed. For this Method02's more demanding informational choice, child owns meaningful information decision or representation, not private records or decorative changes to an adult-dictated message. The same first child-authored choice enacted later remains one legitimate role, not a second independent check; a new uncued decision is assessed only if a distinct genuine need arises, else separate check NOT_OBSERVED. REVISIT: Genuine later date distinct role/use, NOT_OBSERVED.

PK4 C4-3 — Experience a substantively different useful class role

ENTRY: Teacher consults only authentic previously documented role and offers new safe role choice. MODEL: Adult shows different adult-only role, no child leadership ranking. DURING: Learner may contribute actual distinct wayfinding/communication/plan display type, with safe access. EXIT: Fresh real group-use responsibility actually distinct from previous source, else variety NOT_OBSERVED. REVISIT: Later date unlike useful responsibility, NOT_OBSERVED.

PK4 C4-4 — Coordinate a class contribution while respecting others' choice

ENTRY: In safe real class choice, child can opt into actual useful picture/role display. MODEL: Teacher on unrelated adult plan models choice with no peer policing. DURING: Learner creates own real class-benefiting contribution alongside voluntary peers with no forced leadership. EXIT: Functionally different child-owned class contribution made genuinely ready for actual classmates; observed uptake is additional only when witnessed, not a requirement; no adult-only finished board. REVISIT: Actually later different class day, NOT_OBSERVED.

PK4 C4-5 — Show varied responsibilities over natural classroom occasions

ENTRY: Review only actual authenticated different safe real roles before offering new one. MODEL: Adult models other distinct teacher-owned safe community function. DURING: Learner chooses meaningful class role and may take different role types over time; no official count/quota. EXIT: Fresh real safe class-benefiting role plus actually observed distinct earlier roles; do not invent second role. REVISIT: Truly later date with unlike role and class benefit, NOT_OBSERVED.

Distinct original mechanisms

Method 01: Real classroom safe wayfinding/invitation cue chosen and communicated by learner, genuinely ready for actual classmates, teacher retains supervision and verification; immediate peer consultation not mandatory, familiar same location valid. Method 02: Accurate approved nonprivate information/message helper with real group purpose, personally sourced, classroom-use readiness separate from recipient actual consultation. Method 03: Original semantic contribution safety/consent must be observed separately from a later group-serving duty: a safe voluntary true meaningful cue remains partial information if later public role declined or unsafe; a coerced/private/guessed ORIGINAL cue is not sound information evidence even if later service performed. True teacher-authorized choice information for real classmates through safe learner-performed responsibility; child-origin useful option/representation decisions are an additional richer method goal, not a compulsory source-role prerequisite. An adult-written board genuinely delivered by a willing child can show one real duty; an original true child cue observed BEFORE later refusal of actual class service remains only partial meaningful information while the performed role stays NOT_OBSERVED. A child declining before any content cannot be credited original information. Adult-only board, role badge or fictional pupils cannot. Older genuine varied duties can happen in one project/day; optional new independent content and later learner revisit require their own observations.

Four fully written learning delivery modes and limits of directly equivalent official source evidence

SOLO — NOT IMPLEMENTED: Child-only future application can use original prereader narrator and truly independent child-controlled nonautoplay picture-message tasks in a fictional class, with accessible AAC/voice/gesture controls, opt-out and meaningful virtual beneficiaries. It can teach what a classroom role accomplishes without an adult operating the app; nevertheless an avatar class is not a REAL classroom community. Direct official I.C.2 source action remains NOT_OBSERVED absent real learner-to-classroom meaningful contribution. Functional child-only implementation, student privacy, learning parity and actual effectiveness not tested.

CO-PLAY: A trusted adult and child participate in genuine household shared message/welcome picture work, where a real family member may use child-authored output, with guidance and child-owned choice. This is serious transfer practice; it does not automatically become the actual classroom community described by the official standard. Document the real family learning while marking classroom source NOT_OBSERVED until a genuine real class-use action can be observed. No unsafe chores, child supervisory duties or coercion.

ADULT-LED ONE CHILD: One teacher with one child can produce a genuine actual class-use cue for real existing classmates, with ENTRY then separate adult-owned MODEL and authentic child role later, including familiar venue. A home caregiver may do worthwhile related family practice but cannot claim exact official classroom-community role unless a true authorized class link is established. Changed context optional stronger transfer, not required. No extra adult, private peer data or school access without permission.

TEACHER-LED CLASSROOM: Teacher verifies real authorized class purpose, offers safe accessible materials and a willing meaningful role, models unrelated adult-owned example, and individually observes genuine pupil-PERFORMED class-duty contribution (including assigned adult-written information under supervision), separately recording if pupil originated informative content. Real classmates must exist as potential beneficiaries but need not be visibly reading the sign that same session. Record actual uptake separately. PK3 adult assistance permitted and supervision available; PK4 functionally varied roles observed across real occasions, not multiple costume labels. No compelled class service or peer policing.

COMM56-06 — “Various roles and responsibilities” is functional, not a job-title tally: An older child may make two genuinely different useful real class contributions within one integrated project/helper role: e.g. personally choose a truthful class-ready wayfinding cue and on another authentic task personally contribute a different teacher-authorized group-choice display. If the two have substantively distinct function, their role heading being the same does not invalidate variety. Conversely selecting a picture and helping hang the SAME sign are one wayfinding responsibility, not two, even with two movements. Three renamed badges remain zero real additional functions. Shared synthetic helper records role-types and functionally different responsibility-types separately, with a conservative at-least-two authentic-function sanity check that is not an official published numeric cut score, not mastery and not necessarily a one-session requirement.
