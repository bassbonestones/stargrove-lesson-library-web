Three distinct complete lesson methods with unique real-world assessment

1. LESSON_01_ACTUAL_CLASS_WAYFINDING_HELPER.md and facilitator companion

Mechanism: Actually useful safe class activity invitation and wayfinding pictorial helper, with a child-owned truthful accessible cue ready for genuine classmates to use, even before actual peer uptake; peer consultation is recorded only if witnessed. This method differs from other information and class planning roles. Source-faithful actual EXIT: Child chooses an accurate accessible wayfinding cue for a real teacher-authorized class activity and helps make it ready for genuine classmates, even at familiar class location. PK3 adult support allowed/available; PK4 truly different meaningful role types must actually be observed across safe occasions. Different venue and actual witnessed peer uptake are optional stronger evidence, not official gate. Adversarial misconception: Teacher selects all source content and child only wears helper badge: no learner-owned role. Conversely no child is failed merely because no peer visibly consults a real class-ready contribution that day. Genuine real class use/benefit and child decision matter.

2. LESSON_02_SHARED_INFORMATION_HELPER.md and facilitator companion

Mechanism: Genuine accurate authorized nonprivate information/picture-message helper for actual classroom group recipients, meaning of class plan conveyed through child own expressive communication and adult verification; different from locating activity and group choice display. Source-faithful actual EXIT: For a genuinely useful verified teacher-authorized present/upcoming class information purpose, learner meaningfully selects which accurate safe class information to convey or their own semantically purposeful way to represent a true class fact, and the result is accessible and ready for real classmates. Source/application distinction: Official 2022 Texas I.C.2 page15 also permits real age-appropriate adult-assigned class helper contributions; a pupil genuinely delivering a teacher-written true notice can show a school classroom role even without authorship. That demonstrates real helper performance only, not this Method02's additional learner-origin information-choice target. Familiar content/context is legitimate; observed peer uptake is recorded only if witnessed. The same learner-authored choice carried from an early invite into a finished sign is one real source role, not two independent performances. A separately independent end check is documented only when a different genuinely useful child meaning/action naturally occurs; otherwise mark that additional check NOT_OBSERVED without inventing a new class need. PK3 teacher assistance is legitimate. PK4 additionally needs actual genuinely different classroom functions, which may occur within the same project; repeated message decoration or job labels do not establish variety. Adversarial misconception: A puppet posts a fictional event note or teacher supplies all information while child merely points to arrow; no real responsibility or genuine recipient benefit.

3. LESSON_03_COMMUNITY_CHOICE_AND_ROLE_ROTATION.md and facilitator companion

Mechanism: Actual community-benefiting choice display for genuine safe authorized optional class plans plus naturally observed rotation across functionally distinct classroom roles, not merely a single voted preference or repeated cleanup sticker. Source-faithful actual EXIT: A willing child ACTUALLY performing a safe accurate teacher-assigned choice-board service for real classmates can show a genuine source role even with adult-written choice wording; this does not prove child-origin group-choice information. The selected Method03 adds richer original meaningful information/symbol choice when genuinely observed, and an optional separate new uncued information decision ONLY if another genuine useful need naturally arises. An unposted child-authored draft alone is not a completed school duty; if a pupil voluntarily originated a true meaningful cue and then declined publication/service, preserve the earlier partial original information separately while marking the real performed role NOT_OBSERVED. A child who declined before any meaningful cue has no informational authorship observation. An adult doing all service with child posing shows no pupil role. PK3 adult assistance allowed; PK4 requires functionally DIFFERENT actual responsibility acts across genuine occasions, potentially same day/project, not multiple decorative steps. Actual peer reading and later-day learner act recorded separately when witnessed. Adversarial misconception: Teacher rotates pretend paper badges 'leader', 'organizer', 'helper' during a puppet game but no actual class task occurs; labels do not establish real varied community responsibilities.

Seven learning-difference access profiles

Attention/executive: Short genuinely useful real group duty and safe choice, with meaningful break and optional alternate role. Language/communication: Child-selected real class information/role via AAC/sign/home language; readiness and accessibility can be examined without presumed peer use, while actual classmates' comprehension is separately recorded only when witnessed. Literacy/phonological: Class symbols can aid wayfinding but real performed role cannot be replaced by poster recognition. Numeracy: No role-count quota PK3; PK4 various truly different meaningful responsibilities rather than arbitrary time cards. Autism/sensory: No mandatory public performance or forced group service, quiet private alternate beneficial role. Intellectual/developmental: PK3 adult-assisted duty legitimate; PK4 actual diverse child-owned roles, not teacher badges. Physical/motor/hearing/vision: Reachable genuine supplies and child-directed neutral motor proxy for class contribution; no unsafe carrying or public labor ranking.

Construct and consent evidence at distinct moments

Before recording partial information, confirm that the ORIGINAL pupil-origin cue itself was voluntarily expressed, safe, truthful, nonprivate, consequential and faithfully understood; this is SEPARATE from whether a LATER physical/public school service was safe or consented to. A later unsafe, unavailable or compelled role cannot earn school-service credit but cannot erase an already actually observed safe voluntary original idea. An originally coerced, private, invented, copied or adult-guessed cue must NEVER be credited as sound pupil-original information, even if the role was safely performed.

Method01 real-class source protection: One teacher may work individually with one learner in a real class, no second adult needed to model adult-owned example. COMM56-06 — “Various roles and responsibilities” is functional, not a job-title tally: An older child may make two genuinely different useful real class contributions within one integrated project/helper role: e.g. personally choose a truthful class-ready wayfinding cue and on another authentic task personally contribute a different teacher-authorized group-choice display. If the two have substantively distinct function, their role heading being the same does not invalidate variety. Conversely selecting a picture and helping hang the SAME sign are one wayfinding responsibility, not two, even with two movements. Three renamed badges remain zero real additional functions. Shared synthetic helper records role-types and functionally different responsibility-types separately, with a conservative at-least-two authentic-function sanity check that is not an official published numeric cut score, not mastery and not necessarily a one-session requirement. PK3 still may do one genuinely beneficial role with adult support/supervision.
