01 · Real useful safe roles for our classroom

Use actual safe classroom information and actual child/teacher consent. A role serves real classmates when the child's accurate contribution is ready for them; witnessed use is a separate observation.

Classroom activity picture helper

Choose an accurate big picture so classmates know where a safe teacher-approved story or art activity is happening.

Nonprivate group message helper

Show a broad picture or child-authored safe message about the class's current book/art topic, with teacher factual verification.

Group-choice display helper

Help show real teacher-approved safe optional activity choices. Classmates can decline; adult manages the choices.

Pause, switch or ask for help

A child can choose an accessible role, use sign/AAC/home language, get adult assistance or say no.

02 · Three different useful class roles

01 · Safe wayfinding and welcome

For example, if there are two safe approved class spots, a child can choose a true picture cue for either. One familiar real class area is also valid if the child owns a useful accurate accessible cue for classmates. Adult displays it safely; no child escort or peer monitoring.

02 · True nonprivate shared information

For a real approved class story/art topic, learner can genuinely help with an age-safe assigned teacher-written message; that is real role performance but not independent message authorship. For this richer information-helper lesson, additionally invite learner to choose which checked true fact is useful or which personally chosen symbol conveys their own meaning. Teacher checks facts and access. Do NOT use student names, absences, family details, behavioral incidents or medical information.

03 · Community plan choice help

Two real safe group activities are available. Learner helps show actual big choice cards while teacher receives classmates' preferences and keeps class supervision. A peer may choose differently; helper never enforces classmates' choices.

These are different kinds of community contributions, not merely three attempts at tidying. Real class members must be genuine intended beneficiaries; witnessed uptake is extra evidence, not a prerequisite. A fictional class is practice, not classroom-source evidence.
