Objective-level educator guide — Counting correspondence versus cardinality

This is an overarching source-specific educator guide and NOT a counted lesson plan. Follow DEVELOPMENTAL_SEQUENCE.md. Four separately official published 2022 Texas Mathematics outcomes require their own teaching and evidence, even when one activity legitimately supports multiple outcomes.

PK3.V.A.2 — Child counts up to 5 objects with one-to-one correspondence

Source SHA-256 c4d1fbdc3a6f55f283d31f77b978be854e6e5c7156761477474a20fcf2eb918b. The learner uses one appropriate count word per actual item in a bounded real collection with at most FIVE items. Record first item-by-item visit and whether any item skipped or double counted. This is a correspondence C source, not automatically a whole-set cardinality K source.

PK3.V.A.3 — Child counts up to 5 items and demonstrates cardinality by communicating that the last number indicates how many items are in the set

Source SHA-256 854731ee495becf3e89d9f8528f9d488d6b429af84345b93ff614e0edebaf4e1. Child must actually count and independently express that the LAST count word represents the TOTAL in the complete up-to-five collection. An accurate final count word alone, repeated after teacher, is NOT independent K evidence.

PK4.V.A.2 — Child counts up to 10 objects with one-to-one correspondence

Source SHA-256 100af7123ce1ee597e21efcacde650f85641cada3573c04dc15834bd09f23b47. The child owns a one-to-one count of novel real collections up to TEN, including genuinely new six-to-ten examples, with no staff-chosen order and no counting tray spaces as objects. A five-object-only demonstration does not establish full PK4 range.

PK4.V.A.3 — Child counts up to 10 items and demonstrates cardinality by communicating that the last number indicates how many items are in the set

Source SHA-256 9c4c6a839914df977e081c52922b57787e8db12293e8279e0ad6a8cef73d1e9e. The child both counts up to TEN actual objects (with real six-to-ten range) and communicates the last count word as how many objects exist altogether. Correct numeric guess or a teacher-supplied total is not source evidence. A separate genuine independent total is required; count and whole-set cardinality are not interchangeable.

Four distinct teaching plans and corresponding facilitator guides

Lesson 01 Direct collection studio / facilitator 01 teaches safe object-to-word correspondence in real bounded sets then separately probes whole-set total. Lesson 02 Movement count trail / facilitator 02 uses learner-controlled spatial visits to reveal omissions/double counts, not a compulsory mobility standard. Lesson 03 Counting detective / facilitator 03 finds flaws in fictional counted demonstrations and then transfers to independent real counting and whole-set meaning, not merely criticism of a puppet. Lesson 04 Collection designer / facilitator 04 builds a group as instruction then counts and totals a different unannounced real collection at EXIT; building is not separately required by published A.2/A.3.

Progression and misconception remedies

PK3 five is a cap per set; PK4 ten is the cap. Start small at PK3, move from 1–5 to 6–8 then 9–10 for PK4. Record C and K separately, first count sequence, first total, actual child-originated content U, concept hint H versus access-only A, unknown X and actual stage. C = independently one count word per real item. K = independently completed count PLUS last-number meaning for whole set. C and K separately must be audited; do not award K because teacher asks a leading total question. An eight-piece success is not PK3 source evidence. The child may count in home language/sign/AAC with meaningful object correspondence; no written numerals or English-only pronunciation required.

ENTRY is a new untaught set and first observation. MODEL is a different adult-only set with an explicit comparison between counting items and saying how many altogether. DURING teaches on a separate real set, fading teacher pointing, paired lanes, spoken count prompts and “last number” hints. EXIT uses a fully novel object set where first count and first independent total are recorded before feedback and grade-specific bounds honored. REVISIT is another actual date, not a second same-day correction; NOT_OBSERVED until real data exist.

If child skips piece, model “not counted / counted” on another adult set and remove placements for EXIT. If child repeats the last number but never communicates whole total, do not add a scripted question at EXIT and award K: explicitly teach total on different set, later test a fresh independent attempt. If child names total without counting, that may demonstrate other math but not A.2 or A.3. Child-directed motor proxy can be access A only when the child chooses what to count and expresses meaning; staff supplying choices or total is H.

Seven differentiated learning/access profiles and written delivery routes

Attention/executive: separate counted/uncounted zones, fade station reminders; language/communication: learner-authored home language, semantically composed AAC/sign; literacy/phonology: no printed text reading prerequisite; numeracy: start with concrete 1–3 objects before grade cap; autism/sensory: predictable noncoercive pace, large safe pieces; intellectual/developmental: clear adult-only demonstration then graduated independent count; physical/motor/hearing/vision: sturdy washable oversized nonchoking material, accessible reliable neutral assistance and qualified individualized judgment. No tiny coins/beans, food, batteries or forced motor action. SOLO — NOT IMPLEMENTED: future app requires independently selected item IDs, first count-word pairing, distinct total expression and no answer supplied. CO-PLAY: adult supplies objects but not counting. ADULT-LED: teacher logs C/K separately. CLASSROOM: record each child’s own fresh real count and total, not peer chorus. Full four-mode parity, real child learning, physical print, independent specialist approval and genuine later-date retention remain NOT VERIFIED.
