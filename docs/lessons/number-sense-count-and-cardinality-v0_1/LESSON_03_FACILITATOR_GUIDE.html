Lesson 03 companion teacher/facilitator guide — Counting error detective

Paired standalone plan: Counting error detective. This adult instructional companion is NOT a counted lesson. Refer to separate objective educator guide. The four official source objectives and exact source cell hashes remain in their original authoring audit.

Specific teaching mechanism

Deliberately faulty adult/puppet counting can expose common one-to-one errors: skipping a real object, counting one twice, counting empty space, or saying a last word unrelated to the whole set. Critically identifying a puppet's flaw is pedagogical DURING work, NOT independently counting a different real set. A learner must perform the original source verbs later.

Adult preparation, material safety and phase boundaries

Prepare two blank unnumbered child-safe surfaces from ordinary plain paper, washable mat or stable clean tabletop, without any printed total, answer-coded grid or forced path. The included METHOD_03_DETECTIVE_CARDS.html supplies adult-only Model A/B diagrams with visible answers plus a private observation form, NOT two blank learner Detective Windows mats. Keep those teacher-answer panels covered outside explicit M3/D3 teaching, especially for X3; no printer is needed for the blank mats. Provide distinct safe non-swallowable adult-only puppet model objects for controlled mistakes. MAIN stage identities: E3 PK3=3, PK4=6; M3=3 different star objects in correct-versus-incorrect model; D3 PK3=4, PK4=8 unnumbered new objects; X3 PK3=5, PK4=10 genuinely fresh mixed real objects; R3 different actual day and novel set. Earlier small readiness mini-checks do not become X3 by renaming. Never intentionally trick a child into feeling incompetent; mistakes belong to a fictional adult demonstration, not peers. Privately identify exact missing/double-counted object in teacher key, and keep all printed answers away from child independent source assessment.

ENTRY → MODEL → DURING → independent EXIT → real later-date REVISIT

ENTRY: before detective role, offer a neutral new real set and record child's unprompted item-to-word count and whole-set communication. MODEL: adult puppet on different pieces makes one visible intentional duplicate; another consenting adult gently corrects by recounting each genuine item exactly once and stating total. DURING: learner notices a skip in puppet's new setup, proposes repair; educator models on yet another example only if needed and fades error flags. EXIT: puppet fully removed, child independently counts entirely new actual objects with no flaw indicated; assess C and afterward independent K separately. REVISIT: fresh genuine later calendar date with independent set, not a repeated solved puppet scenario.

Contingent misconception feedback and remediation

If learner says puppet wrong because “red looks bigger,” teach object-visit evidence rather than size. If child repairs puppet count correctly but then serially counts a new real set with duplicates, do not credit A.2. If a teacher tells learner “the last number tells how many,” a subsequent copied “five in all” is assisted, not new independent A.3. For language access allow learner-origin sign, AAC and home language; a proxy must not supply which puppet step was wrong or child’s EXIT total.

Four separate official outcome interpretations (apply to this lesson)

PK3.V.A.2: independent one-to-one C count on an actually fresh real ≤5 set; one count word per actual item, no double count/omission, regardless of total statement. PK3.V.A.3: child counts an actually fresh ≤5 set and independently communicates the last count word as the total of the WHOLE group, not a teacher-fed “last” echo. K requires count and cardinality meaning. PK4.V.A.2: independent one-to-one C count on genuinely new real 6–10 items as well as supported small foundations; do not infer upper range from ≤5. PK4.V.A.3: child counts a real 6–10 group and independently states that final count word tells how many there are altogether; distinguish K from merely repeating the end of C. Use separate first COUNT sequence and first TOTAL response fields and U child-origin, H conceptual help, A neutral access and X unknown provenance. If one authentic trial independently demonstrates C and K, it can support both separately; no automatic cross-credit.

Seven differentiated learner/access pathways

Attention/executive: limited items visible at first and predictable phase cues, fade hints for EXIT. Language/communication: self-authored semantically meaningful home-language, sign, or augmentative and alternative communication (AAC) counts and total; never adult-selected messages. Literacy/phonology: don't require numeral decoding as a counting prerequisite. Numeracy: 1–3 real safe items first, later PK3 4–5 and PK4 6–10 with authentic correspondence. Autism/sensory: predictable voluntary safe activity with no speed pressure. Intellectual/developmental: model errors/total on distinct adult material and fade. Motor/hearing/vision: oversized contrast/tactile safe objects and individually reviewed unbiased child-directed proxy; a proxy physically moving child-selected items is access A, not permission to speak the count or total.

Truthful four written delivery modes

SOLO — NOT IMPLEMENTED: future prereader app would have to preserve each learner-chosen item→count-word association and independent last-number whole-set meaning, with unmodeled EXIT and separate H/A provenance; a correct onscreen numeral button is not proof. CO-PLAY: parent arranges the safe set but cannot supply next item or total at assessment. ADULT-LED: educator models on unrelated objects, then records independent C/K separately. CLASSROOM: individual fresh real-object first responses, not choral count or another child's completed set. Real child observations, physical print and safety field acceptance, independent specialist approval, genuine later REVISIT, implemented SOLO and mode-learning parity remain NOT VERIFIED.
