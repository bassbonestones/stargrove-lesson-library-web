Build the Collection

My design space

Use large safe real objects to create one collection in any child-chosen arrangement. The adult speaks the target number in the child's communication language once; the child assigns one next count word to each new object selected. Do not place a printed sample collection of the target amount beside it.

A space for the child's own collection

Optional large blank paper tiles

Adult cuts if safe; otherwise substitute appropriately sized washable child-safe building pieces. Each tile has a blank design and is deliberately not numbered.
