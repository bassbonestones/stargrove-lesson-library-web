Real-data progression — novice grouping → authentic data-to-graphic representation

Exact official sources: 2022 Texas Prekindergarten Guidelines Math V.E.2, printed p.57 (PDF index 56), illustrative Child Behaviors continue p.58. Illustrative behaviors include placing concrete objects/pictures on a floor graph for a preference question, making a check on a yes/no chart for a question, and discussing class graph data. These are examples, not mandates to disclose private food/allergy, pets, transport, home, family or demographic information.

Non-negotiable data integrity and safety

A real graph depicts actual child-observed or collected data, not a favorite answer key, a teacher-filled model, or a made-up roster. Use two accessible, mutually exclusive categories initially (e.g. smooth vs ridged oversized clean classroom art shapes; large circles vs squares), then an optional third. The question must be visible/communicated, with consistent categories and explicit actual source (the object collection, who voluntarily answered and when). Mark the eligibility/observation boundary: if a respondent does not answer, record NO RESPONSE, never falsely record “NO.” For an exclusive-choice poll, one eligible participant makes at most one response to that question; avoid duplicate or teacher proxy votes. For a real-object census, count each uniquely identifiable actual object exactly once, with child selection/classification and placement. If source data change, refresh the graph transparently; if raw results cannot be verified, mark UNVERIFIED rather than guessing. Picture bars must retain one-to-one quantity correspondence or an explicitly consistent pictograph key; one object/one mark is the initial teaching method, not an invented official formal graph-axis or count-to-ten requirement. Never teach or record an unlabeled pile as a chart representing a specified data source.

PK3 source: in actual multi-participant group activity, child helps choose/collect, place, organize or check real contributions together (genuine teamwork). Only child participation recorded as source candidate; a prefilled picture of other children or invented voters cannot stand in for human group participation. Genuine co-play group may be a real small supervised group of participating children/adults if the learner meaningfully participates as an authentic member; do not count child and solo tablet as two people. Adult-led one-child/solo without other genuine participant contributions are precursor practice for this PK3 source until a real group activity occurs.

PK4 source: child actually collects data from a defined real source—which could be actual physical objects in their environment, not necessarily respondents—and organizes those data into a graphic representation with category/data fidelity. Observing a peer poll isn't required, and an adult handing an already counted bar chart is not a child-collected sample. A meaningful EXIT may be a child-directed safe object census into a correctly labeled picture/physical graph; optional child-run voluntary class poll is another path. No need for advanced graph interpretation, statistics, exact numbers, ruler lengths or verbal explanation above published source.

Five evidence phases for every stage: ENTRY a new data source and first child response before teaching/model; MODEL teacher acts on a different set of objects/group question with no scored data leakage; DURING genuine learner data acquisition and chart building with responsive concept help H separated; fresh EXIT unmodeled new source and chart where child action is independent U or directed access-only A; REVISIT on a genuinely later calendar date with new source, NOT_OBSERVED until really performed. On every record include: event ID/date, physical observation or real group encounter, data source provenance, category boundary, distinct source units and counts/responses, graph placement fidelity, child actions, assistance U independent / H adult concept prompt / A child-origin access-only / X unclear, missing responses, and whether graph was made by child/peers/adult. H supports teaching but never counts as an unprompted independent source action. In a group, peer graph placements are not the assessed child's evidence.

Prerequisite ladder

First differentiate an actual item/response from its graphic mark. Then align each real item to one token in the correct category, avoid double-counting/missing entries, and see how the collection becomes a graphic. More complex group questions and graph forms follow only when genuine novice tasks work. Teach response privacy, consent and no public personal ranking. PK3 must first acquire the pre-graph one-to-one act, then participate in a real collaborative graph. PK4 revisits this concrete mapping, then independently defines/collects simple observational categories, labels, checks and transfers to a new real source. If child is not yet comfortable with numerals, labels can be large original pictures, AAC and tactile group boundaries; correct graphical representation, not numeric symbols, is the target.

PK3 stages — real participation in group collection/graphic organization

PK3 G3-1 — one actual group object, one graphic mark

ENTRY: a small real group (not fictional roster) examines fresh teacher-approved oversized safe shared objects; offer child one independently chosen actual object and two unlabeled graphic category spaces. “How could our group show this object's kind on the mat?” Observe first unaided action. MODEL: with DIFFERENT group-safe items educator says “This is a circle; I place one mark in the circle column. One actual piece makes one mark,” using only teacher-owned sample. DURING: group members take turns physically contributing real items, learner places/directs a token once; teacher checks they recognize own contribution. False positive: child drops extra tokens or copies peer's location without item correspondence; adult models different one-to-one example, learner uses new genuine source item/graphic independently. Fresh EXIT: a different supervised real group collects a new group of safe shapes; learner independently contributes one valid item-and-mark to the resulting floor chart, with origin recorded. REVISIT: another real calendar date and group event, NOT_OBSERVED.

PK3 G3-2 — collect and organize multiple genuine group contributions

ENTRY: a real small group makes one optional choice per person about a neutral harmless classroom activity (e.g. quiet drawing vs puzzle); child is asked to help gather/organize actual opted-in responses and indicate their own contribution, no adult chart prefill. MODEL: adult on DIFFERENT objects (not peers' real votes) demonstrates placing one marker per counted physical piece. DURING: child or peer physically adds their own genuine selection and child helps put same-category genuine marks together, no duplicate ballots; avoid recording names. Misconception: each peer's repeated verbal preference becomes another vote, or absent class member assigned a teacher guess; adult models unique source-unit rule on different object set, then a fresh real group sample and independent response. Fresh EXIT: new short group poll with voluntary real participants and new harmless options; child participates in real collection AND organization, not simply watches; record actual response count/child role. REVISIT: later distinct date new real group, NOT_OBSERVED.

PK3 G3-3 — see that one group's graphic represents what really happened

ENTRY: adult privately prepares a real small group with actual verified source objects, and a floor graph intentionally has one placed token missing (teacher makes this a demonstration fault, not actual EXIT). Ask learner what the group can do to check that the picture matches contributions. MODEL: teacher on distinct counted large shapes matches each actual source piece to a mark, spots missing mark and repairs. DURING: child helps real group recount/visually or tactilely compare actual contributions and graph, directs a real missing mark correction, or affirms faithful match. Misconception: learner thinks a tall decorative drawn bar proves more actual participants even when some absent; teacher shows distinct source records versus graph, new group child source check. Fresh EXIT: different verified real group contribution set with a newly constructed graphic, learner independently helps place/check actual marks correctly; exact comparative bar-number vocabulary not demanded. REVISIT: new date, NOT_OBSERVED.

PK3 G3-4 — transfer to a novel authentic group graphic

ENTRY: a fresh real group collects a safe shared question (which of two large art tools the group actually chose for activity) or physical object contributions; child first selects and assists with the group data organization with no adult-directed chart placement. MODEL: separate teacher-only adult object survey; DURING: child contributes and helps group position tokens, notices response/representation link, can request motor proxy. Unmodeled full PK3 EXIT: in a different real group collection and chart, learner demonstrably participates in collecting actual group input and organizing it into a correctly category-aligned graphic, even without independent PK4 end-to-end graph ownership. Participation is substantive, not watching/prefilled chart or clicking fictional voters. REVISIT: next calendar date group with new question/items, NOT_OBSERVED.

PK4 stages — child collects real data and builds graphic representation

PK4 G4-1 — retrieve data-to-mark correspondence

ENTRY: new safe real object set (e.g. 2 large rounded pieces and 3 large angular pieces), separate novice graphic mat, ask child how to display what is actually there; record first child-origin counting/placement rather than given answer. MODEL: educator uses DIFFERENT actual items to show one piece→one appropriate picture token and a visible category label; DURING: learner observes own source set and makes own marks, checks not duplicated. Misconception: child simply copies the teacher-model chart without collecting actual items; teacher models again on alternate set and fresh probe. Fresh EXIT: new real items and child-owned two-category graphic accurately reflecting them, no need to recite numeric values. REVISIT: later date.

PK4 G4-2 — independently collect a complete real source set

ENTRY: present a previously unseen bounded basket of large safe real objects; ask “What could we find out, and how will we show it?” Child picks observable feature (shape/texture), observes/tallies EACH eligible item exactly once, and puts marks on an initially empty labeled original mat. MODEL: on unrelated smaller safe collection educator counts items systematically and fixes inadvertent duplicate, explains “Our graph is about ONLY these pieces we actually looked at.” DURING: child controls inventory boundary and repeated placement, access proxy can move pieces only when instructed. False positive: child reads preprinted number, skips hidden item or counts same piece twice; educator teaches on another basket with item-by-item check, then new uncued basket. Fresh EXIT: different unfamiliar real basket child collects and graphically organizes accurately. REVISIT: later date, NOT_OBSERVED.

PK4 G4-3 — category fidelity and graphic repair

ENTRY: new mixed-texture object set; a teaching picture graph mislabeled category, ask child to inspect object source and construct a true graph, not simply correct a visible teacher checkmark. MODEL: teacher with unrelated objects shows how a smooth item cannot be put in a rough category, verifies every source item and resolves an intentional sample mistake. DURING: child makes and checks own graph, may correct true error with actual source evidence; distinguish legitimate user-chosen attribute grouping. Misconception: child assumes highest illustrated bar is true independent of actual items; teacher models with different objects, then novel child-first source/graphic pair. Fresh EXIT: new actual mixed-category set and empty mat, independently collects accurately and corrects any wrong placement. REVISIT: actual later date.

PK4 G4-4 — optional real-response survey with missing answers kept separate

ENTRY: only when authentic optional consenting real participants are available, child chooses a benign group question with two exclusive options, invites each actual participant once (adult supports consent), and tracks no-response separately; if no participants available, use real-object census as a valid PK4 route, not fictional votes. MODEL: different teacher-only safe object set displays one mark per source, distinguishing no item from no answer. DURING: learner independently marks each actually received response under correct category, keeps eligibility boundary clear, and makes an actual picture/physical graph. Misconception: no-response child treated as “no,” or a person responds twice and count inflated; model different instance, ask child to collect a fresh authentic source. Fresh EXIT: new real response set when safely available OR novel bounded real object set, child chooses categories, collects and graphically organizes. REVISIT: other real date, NOT_OBSERVED.

PK4 G4-5 — independent new-context graphical data investigation

ENTRY: child encounters unknown clean bounded physical collection; first proposes a sensible observation question, defines accessible categories, independently gathers data and puts one mark per genuine observation on blank paper or floor mat. MODEL: different adult-only source after ENTRY if teaching needed; DURING: child checks completeness, labels, one-to-one and factual fidelity; does not need precise graph scale or more-than/less-than inference. Full unmodeled PK4 EXIT: entirely different real previously uncounted object collection (or authentic one-response-per-person consented group question) with child-origin collection AND correctly category-labeled graphic representation generated from actual data. A ready-made picture graph, invented respondent, copied adult bar height, or unsupported guess cannot count. REVISIT: another actual calendar day and new physical source, NOT_OBSERVED.

Three teaching mechanisms that cannot be collapsed into renamed worksheets

  1. Cooperative genuine floor graph — distributed people contribute authentic source marks; PK3's actual group participation is central, PK4 may lead data collection and charting when ready.
  2. Investigator's real-object census — child personally observes bounded real objects, classifies each once and builds a faithful graphic. PK4 alone can meet its source; PK3 uses it to learn graph correspondences before joining a real group.
  3. Source-traceable survey and discrepancy detective — consented voluntary responses or observable objects, explicit question/source boundary, finds missing/duplicated/incorrect bars and independently reconstructs valid chart. PK3 group mode must still be genuinely multi-participant.

Four full WRITTEN routes (ambition similar, actual parity not validated)

SOLO — NOT IMPLEMENTED: Future prereader-owned tablet teaches the one-mark-per-actual-source rule using accessible pictured fictional practice only, then gives child an original instrument for logging a bounded real-world nonidentifying object set, child independently choosing categories, graphing actual observed objects, and checking completeness. This could support future PK4 source if real observation is verified; merely tapping screen-votes cannot establish real data collection. For PK3 group source, a future secure consent-based multi-person shared-room or asynchronous real group event must contain multiple genuine authorized contributors, learner must originate and organize a real group contribution; virtual scripted peers never count. Children may complete tablet tasks child-only with audio, switch/gaze, visual and tactile supported input, AAC, no reading or adult required as interface; absent a verified real group the group-specific source action is explicitly NOT_OBSERVED even if pre-cursor practice is complete. Engineering still needs no-private-data designs, pseudonymous one-response-per-person consent flow, offline integrity, privacy/retention, source provenance logs, real later-date REVISIT and expert safety accessibility review; no functioning SOLO product exists. Comparable ambition is not equal demonstrated learning. CO-PLAY: Caregiver may model on different object set, then child performs personal bounded actual object census for PK4; if aiming for PK3's group participation, arrange a real multi-person household/class activity with at least a real caregiver and child voluntarily contributing independent actual choices, learner participates in collecting and organizing shared graphic, and do not invent absent relatives' votes. One adult teaching one child without shared actual contributions is practice for PK3 group requirement. Use distinct fresh EXIT sources and later real-date revisit. ADULT-LED ONE CHILD: Adult establishes ENTRY with child-origin real object data, MODELS on different props, guides DURING and probes new independent PK4 object census/chart. To assess PK3 source arrange actual consenting small-group classroom/family collaborator involvement, not label dyadic instruction automatically group participation. Child with motor limitations directs placements (A), adult doing sorting/concept selection (H). Keep one record per actual object/response, graph categories and missing-no response separate. TEACHER-LED CLASSROOM: Educator safely facilitates genuine peer small-group two-category floor graphic, each child picks/carries one oversized safe object or voluntarily responds without displaying personal names; PK3 individually observed collection + organizational contribution, not just echoing chart. PK4 learner independently collects bounded class-safe items or consented poll responses, organizes a new chart, and checks source. Use safe anonymous questions (which classroom building material chosen today), no private food/transport/pets/health/family/personality questions or public ranking. Peers' placements are their own, not credited to assessed child. REVISIT on genuinely later date, not merely another station same day.

Accessibility/differentiation: large low floor mats, large nonchoking smooth tokens, tactile raised axes and thick borders, high-contrast shapes with verbal descriptions, no color-only category, hand-over-hand only if learner directs each decision (A), switch/gaze and semantically accessible AAC, home-language/sign. Some children need adult-owned object transport or repeated question; conceptual hints H differ from motor access A. Consult IEP/IFSP/504 and actual family/team if appropriate; a sensory barrier is not a learning disability diagnosis. Never invent group participant counts or secretly record identities. No child mastery, educator validation, physical printed/tactile quality or actual later-date revisit established.

Retrospective graded-stage learning-differences teaching and probes — 2026-11-01

PK3: Child PARTICIPATES IN A REAL GROUP'S activity of COLLECTING actual data AND ORGANIZING it in a genuine graphic representation; ordinary single-child chart or adult-only data collection is not this official action.

Construct boundary: Teacher fills completed chart, invented classmates and votes, passive student audience, graph of one person masquerading as group, or copying decorations do not prove actual PK3 participation.

PK3 G3-1: Access and scaffold: Invite each group child to place one actual safe classroom object into neutral source set and add/choose one pictorial mark for it, with adult modeling on different object. PK4: Child COLLECTS genuinely observed data (objects or authentic voluntary responses) AND ORGANIZES the real results in a graphic representation; no compulsory class survey, axes, numeral notation or statistical standard.

Construct boundary: Teacher-created data set, preprinted answered graph, a chart interpreted but not constructed, fabricated survey replies, duplicates or count-only score omit required child collection plus organization.

PK4 G4-1: Access and scaffold: Show one-to-one source identity using actual large blocks and child controlled neutral pictograph, then fade adult object/mark matching cue. Fade: remove answer previews, not access to language/AAC/motor/vision/hearing. PK4 G4-2: Access and scaffold: Learner independently gathers an authentic complete available safe object source set from defined shelf or table, recording each once; adult checks safety only. Fade: remove answer previews, not access to language/AAC/motor/vision/hearing. Fade: remove answer previews, not access to language/AAC/motor/vision/hearing. Adult model/echo or inaccessible input must be distinguished from not-yet-observed skill.
