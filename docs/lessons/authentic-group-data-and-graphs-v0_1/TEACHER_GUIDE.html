Objective-level educator guide — real data gathering and graphic organization

This overview is NOT a counted lesson. The official 2022 Texas mathematics sources have distinct action boundaries; exact research-cell hashes are in AUTHORING_AUDIT.json. Underlying original PDF layout concordance and qualified educator validation remain pending.

PK3.V.E.2 — actual group data gathering and graphic participation

Published source: “Child participates in group activities of collecting data and organizing it into graphic representations”; SHA-256 d96dbdfe74f4165f743a188f142a8e4a6754385750c5ba3c3fe34e0a117a16db. Source action requires a REAL willing group actually contributing real distinct voluntary harmless data, plus the assessed child's identifiable participation in BOTH gathering and organizing an authentic graphic (picture, concrete-object column, floor graph). No compulsory independent survey leadership or arithmetic totals are mandated. A simulated group, teacher's prefilled chart, mere child's single vote, one-on-one toy sort or peer's work credited to child cannot establish PK3 group action. No safe actual group available: NOT_OBSERVED, never a fabricated response.

PK4.V.E.2 — child-owned real data collection and actual graphic

Published source: “Child collects data and organizes it in a graphic representation”; SHA-256 8e242aa02657364c902288ec9d00fd6162493bb5193fac8d9e35e9671059dd13. The child personally COLLECTS authentic real observed items or voluntary responses, checks which countable units truly exist, and ORGANIZES each once by a meaningful category into a graphic representation. Actual group participation is OPTIONAL at PK4; an independent child-owned real-object census can qualify. Copying adult-filled icons, answering questions about a graph, interpreting teacher bars or inventing classmate votes is not original collection+organization. Sample size is not an extra threshold.

Three distinct mechanisms and lesson companions

  1. Lesson 01 Cooperative Floor Graph + guide 01: actual group members each supply safe distinct responses and child joins live gathering/graphic placement. PK4 child actively manages source-to-mark transfer rather than passively watching.
  2. Lesson 02 Source-to-Mark Object Census + guide 02: personally scan each existing large safe object and match exactly one picture mark, with new explicit actual GROUP CONTRIBUTION variant for PK3 rather than mislabel solitary count as group work. PK4 may independently use real object census alone.
  3. Lesson 03 Survey Provenance Detective + guide 03: first diagnose duplicates, missing/unknown responses and category mistakes in an ADULT-only graph, then genuinely gather fresh live sources and organize an honest representation. Mere detective recognition cannot replace either official action.

What competent instruction and observation look like

PK3 G3-1 to G3-4 gradually increase meaningful real group participation without pressuring public opinions; PK4 G4-1 to G4-5 increase independent source eligibility, category choice, one-record-per-unit consistency, and genuine source-to-graph fidelity. See DEVELOPMENTAL_SEQUENCE.md. Before any learner source measurement, identify whether source unit is one participating human choice or one distinct real object. Never mix both in the same data bar. Use safe benign observations or optional activity choices, never forced disclosure of health, family finances, food restrictions or identity; a child may decline. A missing response is UNKNOWN/NOT_ANSWERED, not a NO vote. Do not add fictional participants to make chart attractive.

ENTRY uses genuinely new data sources prior to model; record actual child role, not assigned adult work. MODEL uses separate adult-owned real objects, counts one source item into one graphic mark, demonstrates missing-data uncertainty. DURING child gathers distinct actual source units and places their own marks on new blank mat; model error correction on separate adult example, fade highlighted category spots/answer bins. EXIT uses a NEW authentic group event for PK3 with assessed child genuinely collecting and organizing, or a new independently collected real set for PK4 with child-built graphic; record U child-origin, H adult conceptual support, A neutral access and X unclear. REVISIT on another actual date and new real source, NOT_OBSERVED until verified.

If a child draws three duplicate votes for one item, show ONE-to-ONE provenance on unrelated real-object adult model then test different real source. If a child simply reads tallest column, explain that reading is different from constructing. If peers complete chart before child arrives, record no independent source action. If a child chooses own survey category but the educator enters all outcomes and plots, record practice not independent. Access supports can physically place child-chosen mark but cannot decide data/category.

Seven access profiles and four written modes

Attention/executive: one observation-to-mark step at a time with faded checklist; language/communication: child-created semantic AAC/sign/home language for category choices and participation; literacy: picture/tactile marks not mandatory printed labels; numeracy: tangible real-one-to-one provenance, no formal bars or numerals requirement; autism/sensory: noncoercive quiet group choice and optional not-answer; intellectual/developmental: small true datasets and clear modeled error, gradually fade; physical/motor/hearing/vision: stable large clean safe real objects, verified meaningful source observation and learner-directed neutral proxies with specialist review. No fabricated peer consent or private identifiers in source repository. SOLO — NOT IMPLEMENTED: fictional NPC group responses cannot fulfill PK3 real group participation; a future independently observed local real-object census could teach PK4, still requires authentic assessment. CO-PLAY: a household adult alone is not necessarily real group evidence for PK3; verify actual group. ADULT-LED: teacher demonstration not child action. CLASSROOM: actual distinct voluntary group roles with privacy and independent response records, no chorus or prefilled chart. Real child mastery, physical printer/field access, educator approval, live SOLO and four-mode equivalent learning remain NOT VERIFIED.

Practical objective-specific educator observation record

For every real-source attempt, reserve separate columns for source ID, grade, observation date, genuinely present real contributors or real object set, exactly what the learner collected, exactly what the learner organized, actual original child decisions, independently created source-to-mark relationship, unused/unknown response status, adult or peer hints, and whether activity was individually or genuinely group sourced. The evidence record should distinguish U learner-origin, H conceptual help, A neutral accessibility support, X uncertain, and NOT_OBSERVED where real events did not happen. Teaching success at identifying a fictional incorrect graph must never silently turn into either source pass. Do not put actual child identifiers or real friendship/person histories into this authoring repository.
