Method 02 — Investigator's Physical Object Census and Picture Graph

First-party 2026-10-30 E2.2 written lesson; read DEVELOPMENTAL_SEQUENCE.md. Official PK3.V.E.2 child participates in group collection and graphic organization (SHA d96dbdfe74f4165f743a188f142a8e4a6754385750c5ba3c3fe34e0a117a16db); official PK4.V.E.2 child collects actual data and organizes it in a graphic representation (SHA 8e242aa02657364c902288ec9d00fd6162493bb5193fac8d9e35e9671059dd13). Mechanism here is evidence-driven one-to-one physical object inventory, distinct from social ballot graph in Method 01 and error-investigation/provenance of Method 03. For PK4 a child alone can independently count/classify genuinely observed real safe objects; for PK3 the technique is a preparatory skill until used in an actual group data activity.

Physical safety, collection boundary, source fidelity

Assemble clean safe oversized blunt nonchoking discrete large shape pieces, e.g. 2 large circles, 3 large squares, all similar thickness/texture so shape categories accessible; vary counts without imposing any official target. Keep separate untouched ENTRY basket, teacher MODEL basket, supported DURING basket and fresh independent EXIT basket. Adult privately enumerates exact physical contents and verifies none duplicate/hidden or unsafe. A bounded object collection of the class's real clean large props is actual data; a drawn picture of three circles is a model and may scaffold, but is not evidence child collected a true physical set unless physical observations occurred. Define source as "all the large safe pieces presently in THIS tray" and category as actual shape/texture. Put actual items out into a counted zone, one at a time; place one same-size mark in the corresponding original ORIGINAL_DATA_INVESTIGATION_CARDS.html blank graphic column. Each item appears once. For tactile access, child directs adult to move pieces and markers without changing their chosen classification; A valid. No tiny tokens, magnets, food, private personal categories, sound or color-only reliance. For actual data results do not preprint 2/3 answer icons on scored sheets.

ENTRY before MODEL: Present a genuinely unseen real basket with large safe pieces and blank categories; “How could you find out what kinds of pieces are really in this tray, and show what you find on the picture mat?” Observe child action before adult touches pieces or names category answers. PK3 in actual real group setting may contribute by moving/source-checking some items to collective graphic; isolated one-child ENTRY is preparatory evidence, not group-source PK3 credit.

MODEL on different physical pieces: Adult brings a different source tray, says “My question is: which kinds of large pieces are in THIS tray? I look at one actual piece, put it in the seen area, place ONE mark in the matching picture column. I don't make another mark until another real piece is seen. Then I check my seen pile against the graph.” Use small, age-friendly actual volume of pieces, but no official numerical threshold. Teacher never models directly on later EXIT objects.

DURING: Child moves/access-directs each object from their practice basket into seen space, organizes marks. Teacher asks “Where did this mark come from? Could we find its real piece? Did we put one piece on twice?” For PK4, let child choose visible category labels and self-correct if mistaken. For PK3, group collaborative collection with multiple real participants supports source. If a learner draws a tall bar because square objects look taller, teacher traces each physical object on different teacher-only source, then fresh source practice.

Unmodeled EXIT: A new sealed (adult prepared but not disclosed) container of safe tangible objects with category contrasts and blank chart. PK4 child-origin collect/observe actual items, label category and construct faithful matching graphic independently, with exact raw source audit optionally checked by teacher only afterward. One mark per seen object remains the preferred introductory inventory scaffold, not the only valid graphical source evidence: when the learner independently produces a clearly keyed, consistent other symbol scale and all real source object/category quantities correspond accurately, accept that authentic graphic; never require scaling or accept teacher-made keys as child reasoning. PK3 must conduct this work as genuine group participation with collaborators, e.g. each peer contributes actual objects to shared bounded pile, assessed child helps collect and organize resulting graphic. A child who merely counts their own two fake “group” toys is a precursor, not the group outcome. Later REVISIT on different real date, NOT_OBSERVED.

PK3 four actual staged activities

PK3 G3-1: ENTRY real safe cooperative group each places an actual one-piece item into group tray, learner first directs one corresponding graphic mark. MODEL different teacher-only shapes; DURING group completes chart; EXIT new genuine group pile with assessed child-origin one-to-one contribution. False credit: graph has three marks for one piece; show different counted object example and new actual group source. REVISIT next real date. PK3 G3-2: ENTRY new group assembles a bounded mixed-source tray from members' real contributions and learner helps gather/represent, MODEL separate adult tray demonstrates one-item-once, DURING child and peers arrange actual items by kind and group make marks, EXIT new small real group and child participates in both gathering and organizing. If adult brought all items and child merely watched, mark supported not group participation. Later date. PK3 G3-3: ENTRY real group items with prepared teacher-only missing mark prompt, learner chooses how to check. MODEL different tray one-to-one audit; DURING learner helps group spot actual discrepancy or confirm accurate graph, EXIT new real group source and learner originates matching/repair under group activity without adult clue. Unverified graphic cannot score. Later date. PK3 G3-4: ENTRY unfamiliar new group safe object source and blank graph, MODEL different teacher-owned set; DURING collaborate in actual source collection/chart organization, full source EXIT fresh genuine multi-person group contributions where child's collecting-and-organizing actions demonstrably connect source to graphic, not copied from model. Later-date REVISIT NOT_OBSERVED.

PK4 five genuine data-collection stages

PK4 G4-1: ENTRY new physical safe tray, ask learner to observe and make one mark per item; MODEL on separate tray, DURING child moves pieces to seen zone, EXIT untouched real tray correctly represented as graphic. Error: one tall column drawn by visual impression, re-teach source/mark map with different adult pieces. REVISIT later. PK4 G4-2: ENTRY new bounded object set, learner independently makes classification choices, counts each one only once; MODEL different set of pieces and marked seen zone, DURING child uses one-source-one-mark, EXIT new physical tray with faithful category graphic. Double counted duplicate source is false credit; repair and fresh EXIT. Later date. PK4 G4-3: ENTRY previously unseen mixed-shape and mixed-color set with shape categories, ask learner to graph actual shape despite secondary color distractions, MODEL another new set with correctly matched picture labels, DURING learner self-corrects category errors, EXIT wholly new source accurately organized. Color-based alternate sorting is also valid if child explicitly selects color categories and graph matches; don't score wrong by teacher's secret desired category. REVISIT later. PK4 G4-4: ENTRY a new optional real group survey could be available, but if not learner chooses own new object set, original question “how many of each kind are here?” and builds graph. MODEL separate adult set, DURING checks source boundaries and one-to-one mapping, EXIT distinct new authentic source with accurate picture representation. No requirement to collect peers' personal answers. Later date. PK4 G4-5: ENTRY brand new actual bounded tray unknown to learner, asks how to show what kinds and how many, child chooses attribute and collects all actual items; a correctly independently chosen graphic scale with visible meaning is a legitimate alternative to the taught one-mark-per-object display, not an extra requirement; MODEL different adult example AFTER first response if needed, DURING learner checks one-to-one tally and category integrity, full PK4 unmodeled EXIT unknown actual object set with authentic child-owned observation + labels + correctly proportional graphic (one mark per object initially). Count labels optional; does not require statistical interpretation. Different-day REVISIT NOT_OBSERVED.

Four complete WRITTEN delivery routes with explicit PK3 limitation

SOLO — NOT IMPLEMENTED: Future prereader-accessible tablet shows teacher-only fictional model, then guides independent child-run real-object census with audio icon prompts, accessible large cards/scanning/gaze/AAC, and a blank child-editable picture graph (one-to-one default, but accurate child-chosen explicit alternate scale also valid). First response to unknown actual object set collected/confirmed by child cannot be auto-completed by animation; provenance needs verification when implemented. PK4 outcome could eventually be observed in child-only interaction with real source. PK3 solo object sorting cannot alone satisfy group participation: a future genuine consented real other-contributor group event must be integrated, and child must actually gather/organize shared data. Without it, PK3 source EXIT NOT_OBSERVED; synthetic classmates are practice only. Software not implemented, no evaluated parity or real child data, future separate-day REVISIT required. CO-PLAY: Adult models from unrelated physical tray, child invents categories and moves large safe items from new actual tray into graph. For PK3, a genuinely willing two-or-more-person group can include adults as well as peers if each actual contributor provides distinct authentic safe items and the learner helps the collective gather AND graph data; handing the child an adult-prepared tray alone is individual practice, not group source. For PK4, child independently collects and organizes new unseen source. For PK3, set up genuine shared multi-person collection, each actual consenting member adds safe objects and child helps group gather/organize graphic; if only adult labels group objects on child's behalf, keep as preparation. Actual later-date revisit. ADULT-LED ONE CHILD: Teacher performs ENTRY on child-unseen actual clean tray, MODEL different props, DURING shared method, then gives truly new unassisted real-object source EXIT for PK4. For PK3, convene real cooperative group (including another willing child/adult who independently contributes source data) and observe child's actual contribution to collection and graphic. If solo adult-child drill only, source not met. Access-only adult moving child-chosen items A, adult concept/answer H. TEACHER-LED CLASSROOM: Teacher uses large actual safe shared object source from several children, rotates supervised station sorting into two big labeled floor columns. PK3 observation requires child actually participates in group collecting and graphically organizing, not only watches. PK4 does another personally chosen bounded real-object inventory, independently labels and graphs it with source check. Tactile textures/shape outlines not color-only, sign/AAC/home languages and motor proxy welcome; no private participant identities or food/pets/family polls.

Adversarial false credit and repairs

False-positive 1: PK4 child sees preprinted three-blue/two-red picture and faithfully draws bars; their physical source was never observed. Why invalid: graphic copying, not child collection. Repair: teacher models with separate real pieces, provides brand new unknown physical tray and blank labels; child independently handles/checks each real source item and makes faithful graph. False-positive 2: a physical object is counted twice because it returns to main tray after graph mark; false extra column mark appears. Repair: change procedure on teacher-only objects to moved-to-seen zone, then new independent tray with child responsible for item-to-mark verification. False-positive 3: PK3 child alone counts props while tablet calls them “our class's votes,” no other participant. Why invalid: violates explicit published group activity. Repair: real multi-person cooperative object collection and actual child group role; if unavailable record NOT_OBSERVED and teach precursor honestly. Residual: full source auditing of real objects relies on accurate adult preparation and actual child operation, difficult to fake-proof digitally; count-to-ten, bar height, category vocabulary and handwriting are NOT extra official thresholds. Internal artifacts do not establish educator acceptance, child learning, physical print, working independent SOLO or learning equivalence across modes.

Retrospective learning-differences remediation — 2026-11-01

This is an INTERNAL AUTHOR WRITTEN instructional revision, not observed child efficacy or delivered software.

PK3: real group contributions carried through child-involved collection and graphic organization

Source action: Child PARTICIPATES IN A REAL GROUP'S activity of COLLECTING actual data AND ORGANIZING it in a genuine graphic representation; ordinary single-child chart or adult-only data collection is not this official action. Teaching/access and fading: Count REAL safe objects contributed or inspected by several group members; neutral accessible tally bar grows exactly one object at a time and child is a genuine group participant. Fresh child-origin check: New class-tool object census: child helps gather actual brushes/pencils with others and represents them visually, without duplicate counting. False-credit adversarial case: Single-child inventory with no peer group is falsely called group data, or same object is counted twice because it returned to table. Teacher fills completed chart, invented classmates and votes, passive student audience, graph of one person masquerading as group, or copying decorations do not prove actual PK3 participation.

PK4: child-collected actual source observations with honest source-to-graphic correspondence

Source action: Child COLLECTS genuinely observed data (objects or authentic voluntary responses) AND ORGANIZES the real results in a graphic representation; no compulsory class survey, axes, numeral notation or statistical standard. Teaching/access and fading: Child independently scopes and collects actually present toy/tools set, labels category with accessible meaning, prevents repeat count and physically or via AAC directs own graph marks. Fresh child-origin check: Fresh art-tool shelf: child records each existing brush and pencil once and builds aligned pictorial rows from actual data. False-credit adversarial case: Counting a prepared picture of six items without collecting any real source, or counting same handled item twice, is not child collection. Teacher-created data set, preprinted answered graph, a chart interpreted but not constructed, fabricated survey replies, duplicates or count-only score omit required child collection plus organization. Seven access profiles: attention_and_executive_function: Use neutral one-object/one-marker exchange and unnumbered broad source tray with actual object return, learner-controlled pause, and vary which data type arrives first.; language_processing_and_communication: Present consent-based broad categories with clear meaningful pictures, optional home-language/AAC responses, and individual private accessible contribution without forced disclosure.; literacy_and_phonological_processing: Use real manipulatives, large image category heads and movable graph spaces without reading/spelling requirements; verify true category membership of each observed source.; numeracy_and_mathematical_processing: Use one tangible countable mark per VERIFIED observation with independent source tracking; allow simple nonnumerical bars or object pictures; distinguish missing responses from zero preference.; autism_predictability_and_sensory_needs: Offer predictable small-group roles and private neutral answer/motor choice, non-sensitive object-count alternatives and freedom not to respond to surveys.; intellectual_and_developmental_support: Demonstrate genuine collection from a DIFFERENT object set, then fade category-highlighting, have child receive actual objects and place graphic marks from each source.; physical_motor_hearing_vision_access: Provide large accessible high-contrast/tactile graph spaces, meaningful spoken/signed/auditory category access, child-directed switch/gaze placement and adult motor assistance without source decisions. Delivery routes (written, not executable): SOLO must not supply the answer or imply working accessible software; CO-PLAY permits neutral caregiver facilitation, not conceptual answers; ADULT-LED uses a different modeled example before an uncued source probe; CLASSROOM checks each learner independently, not choral compliance. Individualize based on real child/family and relevant specialist plans; retain modality access while fading answer hints.

New source-specific group census for PK3.V.E.2

The original individual object census is only preparatory for PK3. The full PK3 lesson calls for an ACTUAL willing peer group contributing large safe real art objects to a shared material pool. The learner actively helps COLLECT genuine objects from distinct group contributors and ORGANIZES their true types on a blank shared visual graph, one mark per existing source item. Adult MODEL uses a different teacher-owned pool; guided DURING fades category placement cues. PK3 independent EXIT requires a different REAL group event and new safe contributions, observing both learner-origin group collection and learner participation in the common graphic. A solitary tray sort, a pretend group or peer-completed chart does not satisfy the official PK3 group participation. With no genuine group opportunity record NOT_OBSERVED.

PK4.V.E.2 independent EXIT instead uses previously unmodeled real physical objects that the learner personally collects and organizes into an accurate original graphic (the taught one-mark-per-source form or a genuinely child-owned accurate consistently keyed alternative symbol scale); a real peer group is NOT compulsory for PK4. For both grades later-date REVISIT must use new real data, remains NOT_OBSERVED, and SOLO is NOT IMPLEMENTED.

Companion 02 — Facilitating object-census and genuine group contribution

Paired plan: Lesson 02 object census, outcomes PK3.V.E.2 and PK4.V.E.2. Distinct objective educator guide. The teacher companion is not another counted lesson plan.

Instructional mechanism

In the personal object census, learner examines actual individually bounded safe objects, moves each into an inspected zone, then initially draws or directs ONE category picture mark for each real counted object as the preferred concrete teaching technique. At source EXIT, independently produced accurate, meaningfully keyed alternative symbol scales are also legitimate graphical organization when all actual observed object counts correspond; such scale use is never compulsory and cannot be adult-supplied as an answer. This reveals missing/double counted sources more reliably than interpreting a completed graph. For PK4 this independent real-object data collection and chart-making can meet both official verbs. For PK3 the solitary method is only a precursor: the COMPLETE PK3 version requires genuine group contribution to a common source pool and the learner's active group collection and graphic organization, with a genuinely willing real multi-person group (which can include independently contributing adults or peers), with the learner actually participating in both group data collection and organizing. Adult-created props labeled as peer contributions do not become real group source.

Material preparation

Adult inspects a real small tray of large clean nonfood/nontoxic nonchoking safe circle/square pieces, with separate counted/uncounted zones and blank tactile/visual two-column chart. Different object types/materials must be reserved for separate ENTRY, adult MODEL, guided DURING, untouched EXIT and real later-date REVISIT. For PK3 prepare an actual voluntary real group material-creation activity, with independently supplied safe large pieces and separate blank group chart. Do not pre-fill source counts or add imaginary contributor labels. Privacy means no names/survey histories in this repository.

Adult script and intentional fading

ENTRY: Offer a real previously unseen group source or PK4 independent tray and ask, “Which actual pieces belong in our graph?” Wait and record learner's first collection/mark choices. MODEL: On DIFFERENT adult-owned pieces show how each exact object becomes one picture mark and only then move the object into the checked zone. DURING: First learner directs which physical piece is inspected and which category receives its single original mark. For PK3 shift from toy tray rehearsal to a real willing group contributing real distinct objects, with learner helping actual gathering and common chart organization. Remove preoutlined bins, adult category pointing and counting answers. If learner duplicates a mark, model one-to-one on different materials. EXIT: PK3.V.E.2 must be a NEW actual group activity where the child helps COLLECT group data and ORGANIZE it in a true representation; solitary toy census is NOT sufficient. A willing child plus genuinely contributing adult or different willing children may constitute real group participation, but adult-supplied counted piles without actual shared activity do not. PK4.V.E.2 uses new real objects personally inspected and correctly graphed independently; one-to-one marks are the default instructional approach, but a learner-understood true keyed different mark scale also counts. No peer group mandated. REVISIT: New real source on a genuinely later date; NOT_OBSERVED.

Diagnosing breakdowns

Child sorts safe objects correctly but never places graphic marks: teach correspondence from real source to graphic on adult example, then new independent source. Child places one count mark for each empty grid box: distinguish present pieces from chart capacity. Child is given completed categories by staff: concept H, not independent U; remove hints and use new items. For PK3 a team might count and graph on the learner's behalf; document who collected and who organized, never assign the group’s collective action as individual's proof.

Seven profiles and delivery routes

Attention/executive: clear counted/unvisited boundary and single step at a time, fade; language: child-owned semantically meaningful sign/AAC/home language for source identity and categories; literacy: no mandatory written category spelling; numeracy: large one-unit tangible marks not formal bar symbols; autism/sensory: quiet noncoercive real participation with genuine peer option; developmental: two categories and a few safe items before unfamiliar larger practice; physical/motor/hearing/vision: perceptually accessible real items, neutral child-directed placement, professional review for valid source interpretation. SOLO — NOT IMPLEMENTED: future real-item dataset could teach PK4; fabricated virtual class does not demonstrate PK3 group. CO-PLAY: adult supplies safe objects and group context if real, cannot decide learner choices. ADULT-LED: note each actual source collection and mark made by learner. CLASSROOM: voluntary distinct group contributors and each learner separately observed. No performed REVISIT, learner efficacy, qualified educator signoff, physical field material approval or four-mode operational parity.
