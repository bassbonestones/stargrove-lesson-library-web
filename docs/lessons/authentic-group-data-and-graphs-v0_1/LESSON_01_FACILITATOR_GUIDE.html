Companion 01 — Facilitating real cooperative floor graphs

Paired plan: Lesson 01 real group floor graph; official PK3.V.E.2 and PK4.V.E.2. This is a lesson-specific adult guide, not a fourth lesson. Objective-level guide defines the source distinctions.

Pedagogical mechanism

Children perceive that every real contributing group member or observed real safe item supplies ONE legitimate mark in a shared graphic. Unlike a solitary object census, cooperative data gathering needs genuinely present voluntary group members. Adults create access to participation, not fictional votes or obligated public preferences. PK3.V.E.2 requires child participation in a REAL group collecting AND organizing. PK4.V.E.2 requires child-owned collection AND organization, which can legitimately occur with actual objects absent a group.

Preflight

Invite a real willing supervised group to answer harmless optional art/activity choices, or to contribute safe large neutral objects; never ask family, medical, financial, diet or identity questions. Prepare a new large blank two-column floor graph, separate adult-only MODEL chart and distinct fresh EXIT activity/source. Decide in advance whether one source unit is one real consenting person's actual response OR one actual physical object; do not mix units. Keep duplicate/unknown/no-response separate; an abstention is not a NO vote. Choose an actual privacy-respecting deduplication move: give each consenting person one harmless large anonymous turn token to surrender once at the choice, or have adult neutrally witness one actual response turn per person without writing names; do not force participation or interpret a missed turn as NO. If units are real objects, keep uncounted source tray separate from already counted tray so a repeated sight is not a second data unit. Teacher validates truthful source boundaries without answering category/mat placement for child. Consent and quiet opt-out remain available. Record only institutional privacy-compliant actual evidence outside source repository.

Facilitation by phase

ENTRY: In actual new group, ask “What could our group put here to show real choices?” Observe assessed child's first genuine collecting or organizing action before model. If no group, do not invent PK3 evidence. MODEL: On different adult-owned pieces place one actual object into one corresponding picture category and explain why a source maps to a single mark. MODEL is adult only. DURING: Let real participants contribute source data naturally, child asks/collects a genuine choice or real object, then helps the group place and verify marks. If teacher prepositions all marks, show a separate example of correct mapping and fade hints. A child can direct a neutral movement proxy but must decide source and category. EXIT: A genuinely different group/survey event for PK3; observe the child actively gathering actual group source data AND helping organize genuine marks. For PK4, an independently collected real-object or genuinely voluntary response dataset and learner-built graphic suffices; teacher-created graph does not. Teaching begins with one genuine source unit → one mark, but an accurately labeled child-origin graph using a consistent alternative symbol scale, when the learner genuinely maintains the true unit/legend correspondence, is another valid graphic—not a required advanced performance. Reject adult-supplied keys, fabricated units and inconsistent scaled pictures; retain simple one-to-one as the accessible default. REVISIT: Different actual calendar date, new source and participant opportunity; NOT_OBSERVED at authoring.

Diagnostic feedback

A child places three marks for one respondent: demonstrate on another teacher-owned source item that one is one, then return to new data. A child thinks every abstention means NO: mark missing separately and discuss why unknown is not an answer. Child adds no data but correctly identifies taller bar: graph reading is useful, not source collection. A peer completed every placement: do not credit the observer. If there is no consenting group for PK3, mark NOT_OBSERVED without framing it as learner failure.

Seven access profiles and routes

Attention/executive: simple visible one-source-to-one-mark routine with fading; language/communication: child-composed home language, sign or AAC to express choice and category; literacy/phonology: picture/tactile categories, no writing prerequisite; numeracy: tangible single-unit representation without symbol mandate; autism/sensory: predictable group choice, quiet or individual participation, no forced public disclosure; intellectual/developmental: demonstrate different safe adult-only items before novel source; physical/motor/hearing/vision: large safe contrasting charts and neutral learner-directed proxy with specialist advice. SOLO — NOT IMPLEMENTED: cartoon crowds do not satisfy PK3 group source; a child-only real-object investigation may someday qualify PK4 if real and witnessed. CO-PLAY: caregiver facilitates real group if available, never invents participant counts. ADULT-LED: teacher models separate props and records two child actions. CLASSROOM: each child's actual role is individually observed, not credited from chorus. No real child observations, genuine REVISIT, independent educator approval, field print accessibility, completed SOLO or parity validated.
