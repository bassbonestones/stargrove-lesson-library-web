Original authored method's concrete learner actions and feedback model

ENTRY E-COMP (2–3 minutes): Before teacher demonstrates a target action sequence, offer child two comfortable ways to respond: gentle tabletop tap or large hand-squeeze/switch activation. Request verbally/signed/AAC an amount, e.g. PK3 two then four, PK4 three then seven. “Make that many taps [or squeezes] and you choose when you're finished.” Adult stays quiet and does not clap an answer or count the taps aloud in sync. Observe actual independently initiated actions and stops. Write down first number of taps, access and assistance. Entry of two numbers is only baseline, not full source coverage.

MODEL M-COMP (4 minutes): With an adult-only instrument adult explicitly states “I'll make three gentle taps. Listen: tap—tap—tap. I decided when to stop. Those were three separate actions.” Show an alternative three gentle squeezes so child understands action choice does not change quantity. For zero adult intentionally does no tap, then says, “I chose zero actions, so I stayed quiet on purpose.” With PK4 also demonstrate ten manageable quiet finger taps as a model only—child need not copy or maintain a beat. Explain that loudness, rhythm style, length and speed are not the quantity; count of distinct events is.

DURING D-COMP (8–10 minutes): Child chooses their own quiet action. Adult requests quantities (PK3 across 0–5; PK4 0–10, perhaps spread over sessions) and gives a neutral “start when ready.” Child initiates actions at any comfortable pace and stops voluntarily; teacher can count silently for observation but should not give audible cues or pulse a matching beat. After child declares done ask “Would you make the same amount using a different action?” If child chooses, they can translate three taps into three squeezes—this is practice transfer, not automatically a decomposing-number claim. On an incorrect first amount, teacher after recording says “Let's check together. I counted four separate sounds, but the request was three. How could you change a new try?” On a fresh supported trial teacher may count with child, but that is H aided; restore independence using another different request.

Misconception-specific repair: Child copies adult’s rhythm exactly → adult asks different quantity and lets child initiate without the adult tapping; imitation is not independent representation. C

Method-specific instructional rationale and preparation: Actual harmless gentle discrete original action opportunity (move broad soft star into bowl, quiet tap one large safe mat or raise chosen sign) with adult tracking only for observation, child controls start/stop. This is a benign purposeful safe source, not a decontextualized card matching/timing drill, and must be actually available if the official source requires real objects/people/child movement.

ENTRY — uncoached original child source, context and provenance

Before any model, an adult requests PK3 two then four, or PK4 three then seven, using accessible number words; the child chooses action type, self-paced unit events, and intentional stopping, not the answer to the adult requested quantity. Record each requested and actually produced amount separately. Child-chosen quantities are legitimate optional discovery/practice, not replacements for these requested baseline probes.

Document actual child first response (spoken/sign/AAC/meaningful self-directed physical action, as appropriate to printed source), grade, which physical/real-source materials or true willing people were available, and what adult said/did beforehand. If no safe real source or no real learner observation, record NOT_OBSERVED, not false child learning or lack of capability.

MODEL — adult demonstrates on different real owned source

Educator demonstrates unrelated adult-owned quiet motion of a different number and stops on own choice, no rhythm that leads child count.

Never model the exact learner EXIT example or pre-answer with a pointing finger/answer cue. The adult's true demonstration is a teaching event and carries ZERO child independent evidence.

DURING — actual child activity, contingent instructional repair and faded hints

Child chooses and initiates each genuinely distinct action for own target amount, can use AAC/switch access and review how many actions occurred, adult fades countdown and does not determine final stop.

Track U (original learner decision), H (teacher supplied answer/semantic next move), A (neutral learner-directed motor/communication/sensory accessibility), X (unknown). Respond to partial attempts with source-specific feedback and a completely unrelated adult-owned misconception example, then let learner practice without blame. Fade H cues before new EXIT, retain essential disability and physical safety A access.

A changed gentle action type is optional transfer, not mandatory. For zero require intentional no-action communication; no adult-led cadence or auto-loop.
