Method-specific instructional rationale and preparation: Safe stable flat original garden tray, up to five oversized harmless seed-proxy counters, genuine clearly labeled named set/boundary, large separate before/after space; no small choking seeds. This is a benign purposeful safe source, not a decontextualized card matching/timing drill, and must be actually available if the official source requires real objects/people/child movement.

ENTRY — uncoached original child source, context and provenance

Before model child places a real original group and actively adds one or more new LARGE objects into that named group, noticing meaningful change rather than adult moving pieces; PK4 may represent addition up to five using any allowed modality.

Document actual child first response (spoken/sign/AAC/meaningful self-directed physical action, as appropriate to printed source), grade, which physical/real-source materials or true willing people were available, and what adult said/did beforehand. If no safe real source or no real learner observation, record NOT_OBSERVED, not false child learning or lack of capability.

MODEL — adult demonstrates on different real owned source

Adult uses different safe oversize adult-owned books and unrelated table to demonstrate one new member joining adult book group, never child's garden objects.

Never model the exact learner EXIT example or pre-answer with a pointing finger/answer cue. The adult's true demonstration is a teaching event and carries ZERO child independent evidence.

DURING — actual child activity, contingent instructional repair and faded hints

Ask what was already IN learner's named real garden group, which new items joined and what remains now, let child physically move actual added objects (PK3), allow PK4 one valid picture OR object OR verbal representation and fade count-leading hints.

Track U (original learner decision), H (teacher supplied answer/semantic next move), A (neutral learner-directed motor/communication/sensory accessibility), X (unknown). Respond to partial attempts with source-specific feedback and a completely unrelated adult-owned misconception example, then let learner practice without blame. Fade H cues before new EXIT, retain essential disability and physical safety A access.

EXIT — genuinely different independent source action

Unseen safe new real original object set and truly new added members: PK3 child independently physically joins and demonstrates genuine numerical INCREASE of named set; PK4 genuinely represents a changed addition of UP TO FIVE with personally selected objects OR picture OR word problem, distinguishing moved-from-elsewhere outside versus same-set rearrangement.

The test is NOT the same adult modeled material, prerecorded answer, outline tracing or identical stimulus shuffled. Record child-owned action independently against each exact printed source ID; an observed age-specific action is a source candidate, not verified developmental mastery.

Seven individually accessible pathways conserving the actual printed skill

Attention/executive: One actual named group and clear genuine arrival with meaningful child-controlled pause. Language/communication: Original before/joined/now description via sign/AAC/home language, no fixed equation words. Literacy/phonology: PK4 valid pictorial OR verbal OR object model, PK3 real physical objects not drawing only. Numeracy: PK3 actual increase of named set, PK4 adding up to five, never new invented arithmetic range or all three modes. Autism/sensory: Large stable soft objects, no small seed props or loud forced counting games. Intellectual/developmental: Adult demonstrates separate real source, faded hints, child-directed true newly added membership at EXIT. Physical/motor/hearing/vision: Neutral learner-directed accessible proxy can move real PK3 objects under child authentic direction, not select amount for them.

Independent source under adapted access: Unseen safe new real original object set and truly new added members: PK3 child independently physically joins and demonstrates genuine numerical INCREASE of named set; PK4 genuinely represents a changed addition of UP TO FIVE with personally selected objects OR picture OR word problem, distinguishing moved-from-elsewhere outside versus same-set rearrangement.
