Adult directions: keep this page separate

Page 1 provides labels, not a test or a whole storybook. Use only words that truly fit your object/place. Handwritten replacements in a familiar language are welcome. Adults can cut out a label or display a whole appropriate page. No child cutting is required.

Page 2 offers optional messages for genuine available activities. STORY TODAY needs a real story opportunity; COME READ WITH US is an invitation that may be declined. GARDEN NOTEBOOK is a sample heading and short text, not a report of an actual child's observations. Place it in a real notebook only when that sample is useful; no fictional report should be presented as observed fact.

Make writing meaningful and accessible

Read words neutrally when needed. A child may notice, ask about or use familiar writing. Images can support print but picture matching alone does not show a connection with writing. Keep your explanations and observation notes off the child label.

Safe, modest evidence

Check size, contrast, distance and established access supports. Adults handle scissors/tape and all safety decisions; no emergency-sign duties or private information. Record actual child response and help. Familiar print and meaningful questions can count as emerging evidence. Neither novelty nor several print genres is compulsory. A group chorus is not each child's evidence.

There are no observed child results, physical/tactile print trials or completed later revisits in this packet. Historical sibling lessons need separate review; use the current Lesson 01 directions.
