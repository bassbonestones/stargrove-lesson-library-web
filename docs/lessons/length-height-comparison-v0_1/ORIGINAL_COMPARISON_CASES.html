ADULT MODEL: shifted-start illusion

The orange LOWER strip extends farther to the right only because it STARTS much farther right; the upper blue strip is actually LONGER. With start positions different, comparing far endpoints is invalid.

ADULT MODEL: truly aligned contrast

Reposition safe real objects so both beginnings align, then compare their actual ends. A later comparison may use familiar or different objects. Record what the adult supplied and what the child showed.

First-party diagram geometry is for demonstration and misconception correction, not direct evidence a real child compared physical materials or an independent test answer.

02 · Equal length, different appearance

EQUALITY — same start AND same end

These safe abstract strips are the same LENGTH although one is much WIDER. A child comparing width instead of length can falsely call the broad piece longer.

SAME FLOOR FOR HEIGHT

Compare the tops against a shared stable baseline. If a short toy sits on a riser, first move it to the same floor as the other toy before comparing the toy heights.

Avoid asking children to rank personal body height. These diagrams illustrate relationships; they are not records of a child comparing physical objects.

03 · Optional real-object investigations

Optional: shifted strip lengths
Use safe broad blunt strips. If the child enjoys an offset-start puzzle, invite a fair comparison. Teacher alignment may be valid setup; distinguish setup from giving the answer.
Challenge: safe stable model heights
Use two low broad stable boxes on the same table. Name the target: box alone or box plus support. Do not introduce unsafe stacks or compulsory trick questions.
Challenge: two separated objects
Supply broad unchanged reference strip for optional indirect transfer; always align identical start. A different tool may be chosen by child and still satisfy genuine comparison.
