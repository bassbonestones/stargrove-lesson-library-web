Developmental sequence — same/different objects → groups with child-origin language

2022 Texas Prekindergarten Guidelines Mathematics V.E.1, printed page 57/PDF zero-index 56. PK3.V.E.1 “Child sorts objects that are the same and different” SHA 8b2b6b110dc7c30ae2d79582e51fcfdde89db00528fdbfce233b1afbf8702f93. PK4.V.E.1 “Child sorts objects that are the same and different into groups and uses language to describe how the groups are similar and different” SHA f15247bc25c6278ea982d8489dce31711cd0731ad926895ef8993fe064d36a05. Both are PRINTED_GUIDELINE_OUTCOME. The p.57 Child Behaviors include sorting vehicles, organizing animals by habitat, and classifying writing tools while discussing properties. Those are illustrative categories, not requirements that all learners know those objects, habitats, exact number of groups or English labels.

Published action: PK3 child meaningfully sorts safe objects that share a recognizable feature versus objects that differ in that feature, with child-origin placements or child-directed proxy; sorting is an action, not simply saying one object is “blue.” PK4 organizes actual objects into meaningful groupings and independently uses language to describe similarities within/across groups and differences in attribute terms. Language may be spoken, home language, signed, or semantically child-generated AAC. Giving group names alone (“red”/“yellow”) without conveying how groups are alike/different is insufficient for full PK4 source, but child expressions may be developmentally brief and supported by access rather than adult conceptual hints. No mandatory mastery of multi-attribute Venn diagrams, changing rule on command, habitat science, letters or pattern extension; teacher can use these as enrichment if properly bounded.

Safety/material design: Oversized blunt clean age-safe actual sorting objects (e.g. safe smooth large colored wooden/foam geometric tiles or large sealed toy vehicles with no loose wheels) or 2D original thick large cards for access, high contrast and tactile differentiability. Avoid mini beads, magnets, marbles, detached pieces, sharp points, food/allergy sensory sorting and child-owned or culturally loaded identity groupings. For discrimination, separately control competing traits: a round red and round blue can share SHAPE despite color difference; a red round and red square share COLOR despite shape difference. Adults privately validate the actual materials and property reference. If vision/touch traits inaccessible, adapt to genuinely perceivable safe texture/shape or voice labels; do not equate sensory access barrier with conceptual difficulty. Real objects strengthen comparison; printed illustrations are practice aids not automatically proof of child physical sorting.

Evidence and instruction cadence for every stage: ENTRY first independent attempt with unseen genuine physical objects before MODEL; teacher uses different objects to demonstrate explicit feature rule; DURING active learner practice with responsive feedback and grade-appropriate accommodations; fresh uncued EXIT with new objects/rule ambiguity controlled; actual later-calendar-date REVISIT, NOT_OBSERVED until performed. U independent child originated; H conceptual adult cue/relation; A child-origin access-only movement; X unclear (teacher or peers may have sorted). Record object identities, perceivable feature/rule and actual consistent placements, evidence of PK4 child-origin descriptive temporal? No: attribute language (same because round, different because one is square), not memorized color chant. A useful sorting rule needs groups of objects sharing specified characteristic, and distinct groups must meaningfully differ. It is not an official requirement that a child articulate PK3 sorting-rule vocabulary or execute all possible alternate rules. Record first response before correction; after H offer different new independent probe rather than treating supported practice as independent source EXIT.

Prerequisite order: establish perceptual access and one obvious matching property, then notice a mismatch and sort small clear sets. Only after that present conflicting color/shape distractors. PK4 retrieves PK3 then explicitly forms groups, explains why each shares something and how groups differ, tries new object types and child-chosen grouping; teacher supports language without prewriting the answer. Learner need not perform a whole V.E.1 outcome at novice first exposure. Classify in multiple brief playful sessions, not an age-gated timed race. Privacy/respect: classify objects, not peers by ethnicity, disability, family status, religion or body traits.

PK3 stages — genuinely organize same/different objects

PK3 S3-1 — notice an obvious shared attribute

ENTRY: give new large safe plain tactile flat circles (two) and one strongly different large safe square, with same texture and color where possible; ask “Which belong together? Show me.” Do not point to pairs. MODEL: teacher on different teacher-owned large models says “These two have the same curved outline. This has corners; it is different.” DURING: child touches/traces/looks at own objects and places two shared-shape items together away from the third; teacher repairs random grouping with distinct other objects, not giving target placements. Misconception: chooses two nearest pieces regardless of trait; demonstrate on other separated objects then new first response. Fresh EXIT: new oversized obviously round vs angular set, independently groups same-shape items without teacher answer. REVISIT: real later date new set, NOT_OBSERVED.

PK3 S3-2 — separate alike and unlike with a simple stable rule

ENTRY: present four new large tactile objects differing in one salient feature (two smooth, two ribbed) and ask learner to make alike piles, do not label groups for child. MODEL: on different large safe objects teacher says “I feel smooth ones together and bumpy ones together. I don't change my rule halfway.” DURING: child sorts own pieces, can gesture shared feature and child directs proxy as A; ask teacher question only after first independent attempt. Misconception: duplicates same piece in two piles or changes criterion mid-sort without clarity; model on teacher-only set with same feature criterion and re-probe novel set. Fresh EXIT: new safe simple-color or texture set, consistent child-led grouping by one trait. REVISIT: new day NOT_OBSERVED.

PK3 S3-3 — same in one way, different in another

ENTRY: new large round red, round blue, square red safe objects; ask child to choose two alike without supplying rule, note if child chose shape/color and whether placements follow their property. MODEL: with different teacher-only colored safe pieces says “Both are round, even when one is yellow. This one has corners, so it does not belong to the round group.” DURING: child chooses shape versus color for own pieces, may test tactile outline, experience that different-looking objects can share one trait; adult avoids requiring child to name both features verbally. Misconception: “not same” because colors differ despite shared round feature, or groups purely by proximity; teacher traces other examples and gives a genuinely new independent set. Fresh EXIT: unmodeled color-conflicting shape pair; child shows legitimate sorting or clear child-directed consistent rule despite conflicting extra attribute. REVISIT: later date new objects NOT_OBSERVED.

PK3 S3-4 — new-context actual sorting with varied material properties

ENTRY: fresh safe oversized toy tool shapes or flat household-object pictures with large clear attribute, child sorts into same/different sets without adult prelabels. MODEL: teacher-owned unrelated safe pieces, states why alike by one selected characteristic and demonstrates actual grouping. DURING: child sorts larger still manageable set, compares against one obvious different item; adapt sensory trait. Full PK3 unmodeled EXIT: unfamiliar tangible shape/color-contradicting set with consistent genuine child-origin sorting by a shared trait and one contrasting group. This documents meaningful PK3 sorting of same and different, not teacher-supplied labels or memorized card location. REVISIT: separate real calendar date, NOT_OBSERVED.

PK4 stages — sorting into groups PLUS child-origin similarity/difference language

PK4 S4-1 — retrieve PK3 consistent alike/different grouping

ENTRY: four unseen safe objects with one clear common shape or texture trait, ask child to group, record first grouping and spontaneous explanation before teacher labels. MODEL: new teacher-owned set shows grouping one feature and says how two objects resemble one another. DURING: child sorts own objects, begins explaining one actual shared property; if random start return to PK3 S3-1–S3-2, not immediately demand complex multi-rule explanation. Misconception: adult prelabels both bins and child only follows colors; next novel unlabelled independent pair. Fresh EXIT: new set, consistent groups and child-origin brief description of what is similar. REVISIT: later date.

PK4 S4-2 — name within-group similarities AND between-group differences

ENTRY: unlabeled two-group safe set round of different colors versus angular of different colors; after child independently groups, ask open “How are these alike? How is the other group different?” before modeling. MODEL: unrelated teacher-only set demonstrates shared within-group outline and different trait between groups in real language, not repeated group title. DURING: learner sorts own pieces and independently tells or signs/AAC “these have curves; those have corners” or equivalent. Misconception: only says group names “blue, red” unrelated to actual shape criterion, or adult feeds sentence; teach other sample and new independent trait explanation. Fresh EXIT: new original ambiguous color/shape materials, child forms two valid groups and linguistically describes a true similarity and contrast. REVISIT: new calendar date.

PK4 S4-3 — re-sort same objects under a different defensible rule

ENTRY: unfamiliar red circle/red square/blue circle/blue square large safe set, ask child to make groups and explain what belongs together. MODEL: teacher-owned unrelated shape-color combinations, shows first “same shape” then “same color” rearrangement with both explanations as valid. DURING: child chooses original grouping, can change rule explicitly and describe how criterion changed, not forced all two-dimensional classifications as official requirement. Misconception: learner places a red round piece in both original groups without noting rule, or switches secretly and calls arbitrary pile valid; model new set with labeled reason and fresh unseen grouped explanation. Fresh EXIT: new valid two-attribute set, learner selects a consistent grouping and linguistic description; optional legitimate resorting shows flexible concept but is not compulsory state outcome. REVISIT: later date.

PK4 S4-4 — explain apparent outlier or overlapping features

ENTRY: new large safe items with mixed traits; one object may share color with one group and shape with another, and ask child to decide group under own stated/indicated rule. MODEL: distinct teacher-only examples where one blue circle shares color with blue squares and shape with red circles; explicitly “It could go here IF we sort by color. Under shape rule, it belongs with the circles.” DURING: child chooses one attribute, assigns each item once and describes how within/between groups relate; teacher accepts alternate valid rule if coherent. Misconception: every blue item should always be in “blue” regardless declared SHAPE rule; teacher shows another example, re-assess novel ambiguous case independently. Fresh EXIT: fresh ambiguous item and two candidate groups, child chooses coherent rule and explains similarity/difference. REVISIT: later real date.

PK4 S4-5 — new original full classification and group explanation

ENTRY: new culturally neutral distinct actual objects (safe texture/shape or purpose) without labels, learner independently sorts and describes reason with spontaneous language before model. MODEL: unrelated teacher-only set illustrating likeness and contrast; DURING: child checks if each piece belongs to exactly one group under chosen criterion, independent AAC/home-language expression; adult fixes errors on different set and offers new. Full unmodeled PK4 EXIT: entirely new safe attribute-controlled set with at least two meaningful groups; child originates arrangement AND actual spoken, signed, home-language or expressive AAC description of what members of a group share AND how groups differ. It need not be a verbose English explanation or fixed taxonomy; one valid coherent rule is enough. A lucky correct pile with teacher-word echo is incomplete. REVISIT: genuinely different calendar date, new set/trait, NOT_OBSERVED.

Different methods and sources they strengthen

  1. 01 Feature-perception and physical sort: real object tactile/visual property comparison and consistent tangible grouping as the core concrete concept.
  2. 02 Rules can switch without changing the objects: counterfactual reclassification of same safe pieces by a different valid attribute; child distinguishes which feature defines current group.
  3. 03 Secret rule / blind listener investigator: child sets or infers a coherent grouping rule and communicates observable within- and between-group evidence to listener; explains rather than merely sorts by teacher template.

Four WRITTEN routes; educational intention similar, no actual efficacy proof

SOLO — NOT IMPLEMENTED: Future tablet for prereaders, no text reading, presents accessible audio/tactile/high contrast originals with real attribute metadata. PK3 drags/taps/switch-selects large virtual objects into child-meaningful alike/different piles, including mixed-color same shapes, with narrated different teacher example, fresh independent EXIT. PK4 child creates groups and expresses semantic group similarity/difference in their own AAC/sign/speech/home language (not merely clicks teacher's prefilled labels); virtual agent can ask an open question and log child-generated relation. New unmodeled objects and different-date REVISIT must be persisted, plus privacy, screen reader, tactile alternative physical kit if needed, scanning/gaze/switch, error-free assignment/re-sort accessibility. Software is NOT BUILT or child-tested. Virtual sorting is representational evidence only, not physical manipulation proof.

CO-PLAY: Caregiver chooses safe big clean objects; child feels/looks/places or instructs access-only helper; adult MODELS on different pieces. PK3 sorts same/different with a coherent feature, no forced speech; PK4 makes groups then independently explains within/between similarities through home language/sign/AAC or voice, even if one valid rule is nonstandard. Fresh independent EXIT uses never-modeled objects. Adult labeling answer is H conceptual help, physical child-chosen placement A access-only. Future separate-day revisit.

ADULT-LED ONE CHILD: Educator conducts first unhinted ENTRY, models different material and language without revealing child's scored rule, DURING corrects one observed misconception at a time, new independent EXIT. PK3 focus on actual sorting action; PK4 requires both coherent grouping and child-origin contextual similarity-and-difference description, supported by accessible expressive choices. Consult real IEP/IFSP/Section 504 team if needed, no diagnoses based on one sensory mismatch. Keep original results and next actual date.

TEACHER-LED CLASSROOM: Whole group sees teacher-only large-feature demonstration; then safe oversized objects at supervised stations and individual turn with separate unseen objects. PK3 child creates alike/unlike grouping; PK4 each child privately chooses/uses a valid common trait, explains similarity of group members AND difference between groups, no copying chorus. Home-language/sign/AAC/tactile accommodations and nonverbal motor proxy available, record independently sourced first response. No sorting children by personal identity, race, body, ability or home situation. Later true date revisit NOT_OBSERVED.

Evidence/cautions: Record exact original object/feature set, first child-origin placement and independent trait explanation, confounding visual order/teacher prelabels/duplicate assignments, assistance U/H/A/X, actual new EXIT and later calendar REVISIT only when observed. No physical-print, real child, educator, working SOLO or four-mode parity validation.

Retrospective graded-stage learning-differences teaching and probes — 2026-11-01

PK3: Child SORTS objects that are SAME and DIFFERENT using a defensible observable property; does not need PK4 verbal group explanation or a compulsory two-bin/color-only test.

Construct boundary: Passive watching, educator piles prearranged, grouping by size of numerals, color mat revealing answer or mandatory explanation cannot be credited as PK3 independent sorting.

PK3 S3-1: Access and scaffold: Use varied large safe circles and squares, adult models on DIFFERENT set how round objects share a property; then fade pointing on untouched set. Fade: remove answer previews, not access to language/AAC/motor/vision/hearing. Novel child-owned source evidence: Fresh red and blue ROUND pieces plus red SQUARE: child groups the two round shapes despite different color. Adult model/echo or inaccessible input must be distinguished from not-yet-observed skill.

PK3 S3-2: Access and scaffold: Provide large real spoons and pencils with safe nonidentical exemplars, invite two stable category piles without printed labels; fade adult 'this one' motions. Fade: remove answer previews, not access to language/AAC/motor/vision/hearing. Novel child-owned source evidence: Fresh different-sized safe spoons and toy cups: learner separates functional alike/different objects, not merely exact duplicate pairs. Adult model/echo or inaccessible input must be distinguished from not-yet-observed skill.

PK3 S3-3: Access and scaffold: Show how red circle and red square can be same COLOR but unlike SHAPE in a separate modeled set; permit child defensible choice of target rule. Fade: remove answer previews, not access to language/AAC/motor/vision/hearing. Novel child-owned source evidence: On novel green triangle and green circle versus blue triangle, child sorts by coherent chosen color OR shape despite overlap. Adult model/echo or inaccessible input must be distinguished from not-yet-observed skill.

PK3 S3-4: Access and scaffold: Vary safe materials, photos versus real objects and group size; maintain child-controlled placement and no teacher color-coded bin. Fade: remove answer previews, not access to language/AAC/motor/vision/hearing. Novel child-owned source evidence: Unmodeled authentic school tools grouped by shared use or form; record child's actual consistent choice, not adult rearrangement. Adult model/echo or inaccessible input must be distinguished from not-yet-observed skill.

PK4: Child sorts safe objects into meaningfully SAME/DIFFERENT groups AND uses real expressive LANGUAGE (speech, home language, sign or own AAC) explaining how groups are SIMILAR AND DIFFERENT.

Construct boundary: Placing objects without reason, saying 'red/blue' from printed bins, a single identical duplicate, or teacher-composed AAC sentence does not demonstrate PK4's sorting PLUS both explanations.

PK4 S4-1: Access and scaffold: Retrieve consistent PK3-style shape sorting on mixed-color items, fade exact-match model and supply accessible explanation on different sample. Fade: remove answer previews, not access to language/AAC/motor/vision/hearing. Novel child-owned source evidence: Fresh pieces grouped by SHAPE despite different colors; child explains 'these both round' AND what makes other group different. Adult model/echo or inaccessible input must be distinguished from not-yet-observed skill.

PK4 S4-2: Access and scaffold: Construct two safe actual tool groups (spoons/cups) with mixed sizes, invite natural language of inside-group shared use and outside-group difference. Fade: remove answer previews, not access to language/AAC/motor/vision/hearing. Novel child-owned source evidence: New brushes vs scoops sorted; child states each grouping's shared function AND how their functions differ, via accessible language. Adult model/echo or inaccessible input must be distinguished from not-yet-observed skill.

PK4 S4-3: Access and scaffold: Use same colored shapes with intersecting attributes, first sort by shape, then learner changes to color rule with genuine regrouping; avoid telling move destinations. Fade: remove answer previews, not access to language/AAC/motor/vision/hearing. Novel child-owned source evidence: Fresh set of red/blue circles and squares: learner sorts by shape and explains differing shared properties of re-sorted color groups. Adult model/echo or inaccessible input must be distinguished from not-yet-observed skill.

PK4 S4-4: Access and scaffold: Add one real object sharing shape with one group and color with another; allow child to justify a consistent chosen attribute rather than enforce unique location. Fade: remove answer previews, not access to language/AAC/motor/vision/hearing. Novel child-owned source evidence: New blue triangle among red triangles/blue circles: learner decides defensible grouping and explains same versus different rule, not teacher's rigid answer. Adult model/echo or inaccessible input must be distinguished from not-yet-observed skill.

PK4 S4-5: Access and scaffold: Offer novel school safe objects whose color, function and size overlap; adult first records child's untouched full sort then invites child-made comparison. Fade: remove answer previews, not access to language/AAC/motor/vision/hearing. Novel child-owned source evidence: Fresh mixed safe art tools: learner groups by meaningful attribute and expresses within-group similarity AND between-group difference without scripted language. Adult model/echo or inaccessible input must be distinguished from not-yet-observed skill.
