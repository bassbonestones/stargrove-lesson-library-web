Method 02 — Same Objects, Different Valid Sorting Rules

Original E2.2 written method guided by DEVELOPMENTAL_SEQUENCE.md. Official PK3.V.E.1 meaningfully sorts objects alike/different (SHA 8b2b6b110dc7c30ae2d79582e51fcfdde89db00528fdbfce233b1afbf8702f93); PK4.V.E.1 sorts into groups and uses language to explain similarities and differences (SHA f15247bc25c6278ea982d8489dce31711cd0731ad926895ef8993fe064d36a05). Distinct mechanism: keeping the SAME real large objects constant while changing a defensible selected feature, teaching that “same” is same in a particular way, not identical in all respects or adult's favorite answer. This method emphasizes criterion flexibility rather than just physical matching or mystery-rule explanation. PK3 is never required to successfully switch rules as an invented official standard; PK4 language/explanation is official but performing two different sorts is scaffold/enrichment.

Preparation and controlled trait matrix

Create multiple independent oversized safe sets with adult-verified pairs: A red circle, B red square, C blue circle, D blue square (use thick safe nonchoking blunt foam or tactile large cards where direct properties accessible). Each set has a distinct color/texture/tactile mark and outline to make attributes perceptible; ensure alternate grouping by SHAPE and COLOR are both logically valid but NOT mix two rules in one grouping. Teacher-only set must differ from child ENTRY/EXIT. Choose additional safe all-texture/color pairs where needed; do not rely on color alone for colorblind/sensory difference. Original ORIGINAL_RULE_DETECTIVE_CARDS.html presents teaching cases without claiming actual physical objects checked or child's mastery. Use blank mats; do not show an answer-key sort to learner before independent EXIT.

ENTRY before MODEL: Give learner a new prevalidated large mixed-feature set; “Can you put things that belong together in groups? Show how you decided.” Child selects natural attribute and sorts without adult hint. For PK3 focus on valid initial same/different grouping, not ability to switch. PK4 after first independent sort ask open “What makes things in each group alike? How are the two groups different?” Record child-authored language. Ask a second time “Could you sort another sensible way?” only as supported extension, not to withhold official source credit if first valid grouping and language already exists.

MODEL with separate teacher-owned objects: Teacher first groups different large safe shapes by outline, says “I am using SHAPE; colors can differ inside one group.” Then on identical teacher-owned objects creates a fresh sort by color, saying “Now I changed my rule. Red things belong together even if their shapes differ. Both ways can be right for different rules.” The physical objects did not change, only chosen property. Crucial PK4 group language describes both within similarity and between difference, not only label.

DURING: Child chooses their feature in own set (perhaps tactile surface vs shape), places each item once, verifies. If they wish, learner deliberately re-sorts by new feature and says/indicates what changed; teacher does not demand a written algorithm. If learner uses two criteria mixed inconsistently, tutor models on unrelated set what one rule means and offers fresh corrected practice. Record rule-switch capacity as extension separately from published PK3 sort/PK4 explain verbs.

Fresh independent EXIT: New unseen large tactile/visual pieces, different colors/outline combination, no bin labels; PK3 independently sorts same/different coherently even with a distracting secondary trait. PK4 independently chooses a coherent feature, organizes actual groups, and produces spoken, home-language, sign or expressive AAC similarity AND difference descriptions. Optional voluntary re-sort is separate, not state-required. Record original selected feature and exact item assignment, not “correct” by sole fixed teacher arrangement. Later REVISIT new date, NOT_OBSERVED.

Separate PK3 stages, without new multi-rule competency mandate

PK3 S3-1: ENTRY simple group of matching safe outlines and one unlike item, no rule given; MODEL different teacher-only shapes, DURING child groups own large objects, EXIT new clear pair/trio. Do not start with confusing dual-feature matrix for novice. Misconception: adjacency used as group criterion, repair with teacher-only feature trace and novel set. Later-date REVISIT.

PK3 S3-2: ENTRY large single-feature smooth/bumpy or round/angular set, child sorts. MODEL unrelated stable criterion and demonstrates no duplicate pieces, DURING learner places each once; EXIT new unlabelled safe set. If group changes halfway from outline to color without coherent criterion, re-teach one-feature grouping then probe independently. REVISIT later day.

PK3 S3-3: ENTRY new two rounds different colors and a differently shaped same-color object, child chooses a legitimate perceptual grouping. MODEL teacher different dual-feature safe pieces and shows valid shape grouping; DURING learner picks one criterion and may experiment with another voluntarily. EXIT novel mixed secondary-trait grouping demonstrating same-in-one-way. No requirement to explain shape/color distinction verbally or re-sort to pass PK3. REVISIT later.

PK3 S3-4: ENTRY unfamiliar actual safe object set with shape/texture contrasts, child chooses original grouping; MODEL another teacher-only set, DURING respond to mistakes, full source EXIT fresh unmodeled real same/different objects sorted coherently by one child-selected attribute even when other details differ. Respect nonverbal source response and sensory adaptation. REVISIT actual future different calendar date, NOT_OBSERVED.

PK4 stages — grouping, explaining, and flexible transfer

PK4 S4-1: ENTRY fresh unlabelled simple safe objects, child groups and expresses how some are alike, MODEL different object grouping, DURING practice; EXIT new grouping with child-origin share-feature language. Do not require switching rules from novice. REVISIT later.

PK4 S4-2: ENTRY new objects with 2 distinct categories; child states/points via expressive AAC which attribute each group shares and how groups differ. MODEL another unrelated set with within/between phrase; DURING learner produces own description, not teacher's echoed words; EXIT new source-appropriate grouping and own spoken/signed/AAC language about similarities and differences. REVISIT later.

PK4 S4-3: ENTRY an unseen valid two-feature set; child chooses whether to sort by outline or another perceivable trait. MODEL different objects twice, explains first and second groupings; DURING child may change criterion and describe shift. Fresh EXIT: another unfamiliar set; one coherent group arrangement with own similarity + difference explanation suffices for state source, optional novel re-sort gives stronger transfer. Do not count unexplained two piles or hidden adult labels. REVISIT later.

PK4 S4-4: ENTRY conflicting trait item e.g. blue circle near red circles and blue squares. Learner declares/demonstrates rule and groups. MODEL separate example “this belongs with round under SHAPE, with blue under COLOR”; DURING learner tests both mental classifications, EXIT new ambiguous item and own actual reason. False-credit: learner shifts rule mid-explanation to excuse any placement. Teacher models another one-rule set, then new first child response. REVISIT later.

PK4 S4-5: ENTRY novel safe real set grouped by child-selected defensible criterion, own explanation before teacher MODEL. MODEL on different set if need, DURING compare alternate sensible feature if ready, full unmodeled source EXIT: different unlabelled set, own grouping AND expressive statement about what objects within a group share and how one group differs from another. A consistent new rule is accepted even if not the teacher's original grouping; language not all grammar or exact vocabulary. REVISIT other actual calendar day, NOT_OBSERVED.

Four complete WRITTEN route specifications

SOLO — NOT IMPLEMENTED: A future prereader app reveals a randomized safe large virtual object set with visibly/tactually describable metadata. PK3 child chooses one perceivable feature and independently sorts, without any automated snap-to-correct prelabels; may optionally try new rule. PK4 adds child-chosen grouping and requires child-origin meaningful expressive language, including independently selected existing AAC symbols/phrases about within/between properties using home-language voice, sign-access interface or actual child-origin meaning via AAC, including independently selected preprogrammed descriptive words or phrases that truthfully communicate both similarity and difference; never an answer-coded complete correct phrase chosen or highlighted by adult/system. Different teacher-model and new uncued EXIT materials, future real-date revisit logging, switch/gaze/audio/screen reader, visual contrast, motor accessibility, privacy and fair feature metadata must be ENGINEERED/TESTED; no working independent SOLO or physical-transfer proof.

CO-PLAY: Caregiver provides oversized real safe mixed features; learner selects trait and physically re-sorts or directs access helper while adult uses a different safe demonstration. PK3 valid same/different sort enough; PK4 child constructs groups and independently tells caregiver one similarity and one difference, language home/AAC/sign accepted. Caregiver can ask “How do you know?” open-ended but cannot provide criterion during scored EXIT. Offer new untouched source pair and different actual-date revisit.

ADULT-LED ONE CHILD: Tutor controls lesson pacing, starts one-salient-attribute PK3 path before tempting mixed-matrix rules, visually/tactile supports safe access, models with different props, observes mis-sorted objects and specific correction, then new first-origin EXIT. PK4 groups and linguistically compares under chosen rule; if adult precolored bins, record H and new unhinted independent source pair. Individualized IEP/IFSP/504 advice may guide access; do not confuse English-language delay or color vision with math deficit.

TEACHER-LED CLASSROOM: Adult models changed rule with DIFFERENT large actual pieces to group, supervised stations offer different sets, each student privately sorts novel group and (PK4) individually explains similarities and differences to teacher without peer chorus. PK3 tactile/motor child-origin placements count even if no spoken word; record U/A/H/X and first original rule. Optional voluntary resorting extension, no rigid time pressure. No people sorting by family/race/body/ability and no tiny manipulatives.

Material false-positives and corrective teaching

False-positive 1: learner memorizes teacher's only answer “all blue together” and produces same grouping when asked by shape, with mixed shape in same group. Why false: rule mismatch, fixed-bin copying, does not understand same with respect to what. Correction: teacher on DIFFERENT safe items demonstrates coherent single rule and separately changes it, then child independently sorts a new mixed-attribute set with learner-selected feature. A consistent color sort IS legitimate if chosen and explicitly distinguished from shape sort; do not mark alternate coherent answer wrong.

False-positive 2: child switches from shape to color halfway through placing objects, resulting in one inconsistent pile, then says both rules after the fact. Correction: slow down to one perceivable feature in separate sample, have child choose criterion first, new uncued EXIT with unlabelled objects and consistent assignments. The optional rule switch is practice, not mandated source proof.

False-positive 3: PK4 performs two flawless rearrangements but supplies no independent linguistic description of similarities/differences; educator credits sorting count. Correction: teacher models distinct group language on unrelated material, asks learner to tell blind listener the actual shared/different properties of another new grouping in home language/AAC/sign. Limit: re-sorting is complex for some PK3 learners, therefore older-child extension only. Internal tests and print preflight do not demonstrate real child, independent qualified educator, physical printing, implemented SOLO, later revisit or mode parity.

Retrospective learning-differences remediation — 2026-11-01

This is an INTERNAL AUTHOR WRITTEN instructional revision, not observed child efficacy or delivered software.

PK3: actually sorted safe real objects by meaningful same/different attribute

Source action: Child SORTS objects that are SAME and DIFFERENT using a defensible observable property; does not need PK4 verbal group explanation or a compulsory two-bin/color-only test. Teaching/access and fading: Re-sorting may be optional enrichment; PK3 gets a clear new rule on original mixed-property objects without being required to explain rule shift verbally. Fresh child-origin check: New mixed triangle/circle with shared colors: child performs meaningful sorting under chosen color or shape criterion. False-credit adversarial case: Teacher picks new rule, labels every position and child moves identical exemplar only; artificial compliance not actual new-context sorting. Passive watching, educator piles prearranged, grouping by size of numerals, color mat revealing answer or mandatory explanation cannot be credited as PK3 independent sorting.

PK4: independent attribute groups plus expressed similarity and difference grounded in actual objects

Source action: Child sorts safe objects into meaningfully SAME/DIFFERENT groups AND uses real expressive LANGUAGE (speech, home language, sign or own AAC) explaining how groups are SIMILAR AND DIFFERENT. Teaching/access and fading: Let learner legitimately regroup same mixed-color shape collection under second coherent rule, narrate actual similar and different properties, not arbitrary reseating. Fresh child-origin check: Fresh mixed circles/squares in red/blue: learner independently selects one coherent rule, sorts the entire unseen real set and expresses in their own meaningful language (including independently chosen preprogrammed AAC vocabulary) what group members share and how groups differ. Optional enrichment, only if desired and accessible: learner re-sorts the same objects by a second coherent rule and explains what changed; record this separately, never as a source pass requirement. False-credit adversarial case: Teacher announces new rule and physically relocates every object; adult language plus child copying masks lack of child-authored explanation. Placing objects without reason, saying 'red/blue' from printed bins, a single identical duplicate, or teacher-composed AAC sentence does not demonstrate PK4's sorting PLUS both explanations. Seven access profiles: attention_and_executive_function: Present a small safe set with shared and contrasting attributes, neutral uncued bin spaces and predictable turns; model change of rule on DIFFERENT objects then fade colored bin edges.; language_processing_and_communication: Accept learner-chosen sign, home-language, semantic AAC or original photo descriptions of group similarities AND differences; neutral translation, not adult-completed scripted reason.; literacy_and_phonological_processing: Use real original safe tangible objects that differ in color, shape and use, with unlabeled sorting spaces; no written word decoding prerequisites.; numeracy_and_mathematical_processing: Vary group sizes and allow more than two defensible piles; contrast actual color, form or purpose while removing numbered bin markers.; autism_predictability_and_sensory_needs: Offer predictable quiet visual or sensory-safe tactile objects, no compulsory touch, learner-directed private response and preview a new sorting criterion before practice.; intellectual_and_developmental_support: Model sorting on different safe items with explicit 'same round despite colors'; fade picture outlines, adult sorting and single correct bin.; physical_motor_hearing_vision_access: Use large nonchoking high-contrast/tactile shapes with reliable audible descriptions and child-controlled gaze/switch proxy, preserving real category decisions. Delivery routes (written, not executable): SOLO must not supply the answer or imply working accessible software; CO-PLAY permits neutral caregiver facilitation, not conceptual answers; ADULT-LED uses a different modeled example before an uncued source probe; CLASSROOM checks each learner independently, not choral compliance. Individualize based on real child/family and relevant specialist plans; retain modality access while fading answer hints.

Explicit objective-specific EXIT and later transfer interpretation

PK3.V.E.1: On the completely unused real-object EXIT bank, invite the learner to independently sort all same/different items into a coherent grouping. A first-response child-selected rule is valid if the actual objects support it; no second-sort criterion, blind-listener explanation, spoken comparative sentence, or category label is required by this published outcome. Later-calendar-date REVISIT is fresh physical sorting and remains NOT_OBSERVED until witnessed.

PK4.V.E.1: On a different untouched real-object EXIT bank, first observe the learner grouping objects, then elicit an independently formulated similarity property within groups and meaningful difference between groups. Both the child's actual sorting and source-specific original language (home language, child-origin sign/AAC or speech, including genuinely child-selected stored descriptive AAC words/phrases that communicate the actual within-group similarity and between-group difference, not a device/adult chosen complete answer) are necessary; another person's guessed secret rule, rote category labels, or adult-composed message cannot stand in. Genuinely later-date REVISIT observes both physical grouping and meaningful relational language without hints; remains NOT_OBSERVED.

Companion Teacher/Facilitator Guide — Lesson 02: Same Objects, New Rule

Pair: Lesson 02; official objectives: PK3.V.E.1 and PK4.V.E.1. This companion guide does not count as a separate plan. Consult objective educator guide.

Why this method is different

The child keeps an actual set of objects constant while noticing that group membership changes when the selected attribute changes. The instructional counterfactual (“same objects, new meaningful rule”) clarifies that sameness is relational, unlike Lesson 01's direct sensing and Lesson 03's blind-listener communication. Two successful re-sorts are NOT an official attainment requirement: one genuine sort satisfies PK3's source action; one coherent group sort plus own comparison language can satisfy PK4's candidate action.

Preparation and material independence

Prepare at least four oversized adult-inspected safe sets with cross-cutting attributes: A red round, B red angular, C blue round, D blue angular, or a non-color alternative using raised textures and outlines. Keep ENTRY set separate from adult MODEL, DURING, untouched fresh EXIT and a further collection on a different date for REVISIT. Make all objects nonchoking, clean, graspable or switch/gaze-addressable. Have two unlabeled blank mats and a record grid for each child's rule, actual placements and PK4 phrases. Original detective cards are optional teaching supports; printed color is not an accessible source-evidence default.

Step-by-step facilitation and fading

  1. ENTRY: Before showing a sort or verbalizing a hidden target, ask “Put together the things you think belong together.” Write down the child's initial stable criterion, including a valid unexpected grouping. For PK4 ask the child to explain similarities within and differences across their chosen groups; don't demand a second sort.
  2. MODEL: Using different teacher-only four-piece objects, sort first by outline, describing the shared trait; reassemble those same adult objects and sort by a different meaningful attribute. Explain “The objects didn't change; the rule I chose changed.” For PK4 articulate concrete group similarities AND group differences.
  3. DURING: On new practice objects, invite the child to try an initial coherent sort. If ready, ask how else the SAME objects might go together. Use prompts that ask the child to compare features, not “put blue here.” Help the learner notice that within a given sorting pass the selected criterion cannot flip invisibly. Praise the reasoning, not matching the adult's preferred piles.
  4. FADING: Remove visual labels, pointing hands, rule reminders and verbal sentence frames in stages. An adult's rule-specific directions count H, never independent U; a motor proxy carrying out a child's explicitly chosen placements is A. If rule changing creates overload, reduce to one successful child-owned criterion; no invented switching threshold.
  5. EXIT: With a never-before-shown mixed-feature set, ask the child for their OWN coherent physical sorting. PK3.V.E.1: observe the full same/different sorting action without imposing language or switching. PK4.V.E.1: also capture learner-selected meaningful within-group similarity and between-group difference in speech, home language, sign or AAC, including independently chosen preprogrammed descriptor words/phrases; a full correct answer supplied or highlighted by adult/system is H. One complete child-origin sorting plus accurate relation is official source candidate; a second re-sort is optional enrichment. Do not use correct placement after verbal correction as fresh EXIT.
  6. REVISIT: On a later calendar date, introduce a new real accessible array. Observe one first-response sort and (PK4) language before any reminder. Record NOT_OBSERVED until this occurs.

Diagnosis and appropriate response

Child changes rule mid-pile: On a different adult set demonstrate why a shape pile cannot suddenly contain a blue square simply for being blue; choose one rule per sort, guide practice, return to untouched new EXIT. Adult insists on shape but child chooses color: Accept another coherent criterion, record chosen feature. Child cannot tolerate transition: Preview alternative sort as an optional investigation, stabilize first rule rather than score a switch failure. PK4 says “red” after adult points: Ask about actual within-group commonality and between-group contrast during supported practice, then use genuinely new objects without words/labels supplied. Perception of color is unreliable: Use tactile contrast, edge shapes, narrated feature access or locally meaningful use categories; avoid claiming an equivalent valid assessment without professional review. Copies teacher placement: Stop counting adult-led piles, remove answer clues and reset with new items.

Adaptations across seven required profiles

Attention/executive — consistent first-sort routine and one optional transition, then fade table arrows; communication — child-origin semantic AAC/sign/home-language for PK4, including independently selected meaningful preprogrammed words or phrases rather than an obligatory newly composed sentence, PK3 sorting may be nonverbal; literacy — word reading never required; numeracy — no tally or exact-two-groups quota; autism/sensory — predictable preview and optional non-touch exploration; developmental — reduce to obvious two-class contrast before optional two-feature crossover; physical/motor/hearing/vision — tactile/large safe forms, accurate descriptive access, child-directed motor or gaze proxy with A recorded. Distinguish a missing sensory channel from a missing classification concept.

Mode-specific delivery

SOLO — NOT IMPLEMENTED: Future interactive engine must make criterion changes genuinely learner-controlled, remove answer-coded previews and support actual PK4 expression; virtual action is preparation, not automatically real-object mastery. CO-PLAY: Caregiver refrains from predicting “correct” rule, handles only learner-directed large props. ADULT-LED: Educator marks each distinct first sort, hints and final new probe. CLASSROOM: Demonstrate alternation with adult-only objects; each child uses an unseen private set, and independent PK4 explanations cannot be replaced by group chorusing.
