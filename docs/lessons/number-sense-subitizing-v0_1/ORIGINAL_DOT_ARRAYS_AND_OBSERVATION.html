Nonleading instructions

ENTRY: Observe first answer before modeling. MODEL: Explicitly show different grouped/new dots. DURING: Genuine practice with targeted explanation; tag conceptual help. EXIT: For PK3, use G–I (unseen quantities 1,2,3). For a PK4 whole-range 1–6 candidate, use G–I as additional PK4 cards (only if the PK4 learner has not seen them) plus P–R (4,5,6), or substitute equally novel 1–3 arrays when needed. Six PK4 trials may be split across real sessions; unobserved sizes remain gaps. Shuffle presentation order, not the dots within an individual card. Don't tell the size, highlight a grouping, or compare a dice face. REVISIT: Actual separate date with entirely new real-object configuration; not represented by these same cards.

A correct quick number choice cannot prove an unseen cognitive strategy. Ask “How did you notice?” only after recording first answer; note observed serial counting or volunteered subgroups but don't diagnose ability or measure milliseconds.
