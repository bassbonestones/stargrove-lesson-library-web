01 · If a real disagreement naturally happens, I can get help

Original optional teaching choices. Do not create an argument or distress to use these cards.

Ask a trusted adult

“Please help me.” I may use speech, home language, sign, AAC or a meaningful child-selected gesture. Adults respond to safety needs immediately.

Choose a safe different way

I may ask to use an available different item, choose another activity, or request an optional turn only when everyone wants to.

Ask for my own space

I can ask for a quiet, safe place or tell someone I need space, with adult help if needed.

Pause or stop

I can stop talking or playing, seek trusted help, and take a safe break. No forced reconciliation.

Safeguard: Never hide toys, provoke sadness/fear, stage peer rejection, deny basic needs, force eye contact/touch/apologies or require a child to solve unsafe conflict. These text choices are adult-supported CALM PRACTICE; real source requires actual naturally occurring real disagreement, and if none occurs mark NOT_OBSERVED.

PK3 and PK4 difference

PK3: seek real trusted ADULT HELP during genuine disagreement with ANOTHER CHILD. PK4: child initiates relevant safe problem-solving strategy with others and seeks adult support WHEN NECESSARY, not only after failing alone.
