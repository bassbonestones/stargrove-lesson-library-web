Companion Facilitator Guide 01 — One-to-One Partner Laboratory

Pair: Lesson 01. Sources: PK3.V.A.8 / PK4.V.A.8. This adult companion is not a counted lesson; source criteria and progression are in objective educator guide.

How correspondence teaches this specific mechanism

An independently selected partner for every item makes equality concrete: no leftovers means same quantity; a leftover on side A means A has more than B. The adult must not prearrange correspondences or supply the relational sentence. The child may compare by another defensible count strategy at EXIT; partner drawing is not a mandated extra attainment criterion. PK3 children compare within five per group; PK4 extends above five up to ten per group.

Practical preflight

Prepare first independent ENTRY two-versus-three on an original safe large set pair. The adult MODEL uses a separate two-versus-two matching pair and two-versus-four contrast, never the exact child's source bank. Fresh DURING pairs include PK3 three-versus-four and four-versus-four or PK4 six-versus-seven and seven-versus-seven. Independent EXIT shows truly new, unpaired, unknown PK3 five-versus-four and three-versus-three or PK4 nine-versus-ten and eight-versus-eight, with no disclosed answer or completed matching. Safely reuse a familiar accessible item type if its actual layout/count has not been seen; a different material type can broaden transfer but is not a source-validity requirement. At later actual REVISIT use new unknown amounts/layouts, with material type flexible for a child's access. For sensory access use accurately described raised/contrast objects, not printed “answer” color. Bound sets visibly without leading labels. Record source ID, each set quantity, first child-origin directed comparative language, actual pairing/matching if done, prompting U/H/A/X and date. No tiny counters or real food.

Adult interaction and fading decisions

ENTRY: “Look at collection A and collection B. Is there the same number? If not, which has more than the other?” Observe first child strategy without demonstrating on this bank. Correct response must identify a relation, not say an unattached “five.” MODEL: On adult-only distinct objects, physically create one-to-one partners and narrate “Everyone has a partner; they have the same number,” then “This side has one without a partner, so it has MORE than that side.” Demonstrate a converse fewer relation when appropriate. Remove model. DURING: Let child place or direct each pair on new real pieces; ask “Who still needs a partner?” If child compares row length, spread apart another practice set, rematch without adding tokens, and let learner re-evaluate. If child has counted only one group, ask for two group referents. Fade teacher pointing, prefilled matching lanes, hinted words and adult-selected partner targets. EXIT: Give entirely unseen physical pair(s). PK3.V.A.8: independently compare two sets each ≤5 using meaningful referent-specific comparative LANGUAGE; PK4.V.A.8: compare sets with accessible near-ties/equality through ≤10 using self-origin comparative language. A trained proxy can move child-specified items as A, but adult-supplied count or relational label is H. A guessed side or “bigger toy” criterion is not independent quantity comparison. REVISIT: At a genuinely different calendar date, another novel set and independent original relation. Record NOT_OBSERVED until actual observation.

Diagnostic feedback ladder

If “longer is more,” teach distance is not a new item on an unrelated teacher bank, then let child pair own new practice set. If says “same” because both are blue, vary color while preserving number; ask for reliable pairs. If child cannot identify collection boundaries, reduce set size and mark only the two collections, then fade boundary cues—not place answers. If reluctant to grip, use child-directed switch/gaze or neutral proxy without assuming equivalence to independently placing items. If child says true “B fewer than A,” accept it even if adult expected “A more than B”; reverse referents only to clarify, not to manufacture a false error.

Seven differentiated needs and four routes

Attention/executive: predictable one-pair-at-a-time routine, fade count tracks; language/communication: meaningful child-authored home language/AAC/sign relation; literacy/phonology: labels read by adult as access, no print demand; numeracy: accessible tactile real one-to-one scaffold, gradual fade; autism/sensory: clean low-texture alternative and quiet predictable bank; intellectual/developmental: begin 1–3 pairs, then untaught larger EXIT at appropriate stage only; motor/hearing/vision: oversized high-contrast/raised shapes, neutral child-directed proxy, accurate quantity descriptions with team review, not answer-coded prompts. SOLO — NOT IMPLEMENTED: future accessible digital item-pairing and comparative response must let child originate all decisions and survive an uncued new EXIT. CO-PLAY: caregiver can physically handle learner-directed pieces, not pair on child's behalf. ADULT-LED: individual preflight for numerical versus visual access and H/A separation. CLASSROOM: teacher models one unrelated set; privately score each learner's own new two-group comparison, not peers' or chorus. No real child outcome, physical field QA, independently approved accessibility, completed later REVISIT or validated mode parity.
