Compare two sets: more, fewer/less and the same/equal — PK3 to PK4

Original universe-neutral E2.2 written curriculum draft · October 30, 2026 · internal author review, not delivered instruction. The 2022 Texas Prekindergarten Guidelines (Mathematics V.A Number Sense, official PDF page index 51, printed page 52) publish two distinct outcomes:

  • PK3.V.A.8: “Child compares sets of objects up to 5 using comparative language (e.g., more than, less than, same number of)” — original research-cell SHA-256 779846ea0d4de0ae83ba66c391b769a1083f33ff90d75227c90c87579cdb0dc4.

Exact meaning and curriculum boundary

Both grades require comparing the numerical quantity of two actual represented sets, communicated with comparative language or an accessible language-equivalent symbol/AAC/sign/meaningful child-selected relation. A silent point at a visually longer row, copying “more,” reciting count words, counting one set alone, matching numerals on cards without connecting them to collections, or rearranging a single set is not automatically evidence of the source verb compares. A child can compare meaningfully through aligning objects one-to-one, counting both sets with cardinality, or explaining an unmatched remainder. Require source-specific child decision about which set relative to which other set and relational expression—not a particular count algorithm. Home-language `más / menos / igual`, sign, meaningful AAC icons and child-authored pointing to an explicit relational choice are valid accessible communications of a quantitative idea. Do not impose English-only pronunciation, symbols `>`, `<`, `=`, timed verbal explanations or mandatory written numerals. PK4 may use “greater/more,” “less/fewer,” or “equal/same” synonym pairs; knowing all synonyms is not an additional source obligation.

The range applies to each comparison set: PK3 sets 0–5; PK4 sets 0–10 (zero optional introductory opportunity to reason about empty group, with teacher confirmation of published interpretation). Starting with 1–3 is a developmental teaching stage, not a redefinition of the full source range. PK4 must revisit the PK3-size comparison and then generalize to 6–10 including tight near-ties 7 versus 8, equal groups with unlike arrangements, and direction reversal. No rule says child must compare 10 only, count every size on one day, or independently show every possible ordered pair to get a curriculum candidate. A representative varied fresh EXIT samples more, fewer/less and equal/same plus a PK4 larger-size relation; this is an internal instructional sample not a state-cut score. Comparisons are mathematically relative; “three is more” without an identified second set is incomplete. Equal-sized groups can be different colors, shapes, lengths or arrangements; spatial extent is not amount.

Related but separate source verbs: PK3/PK4 V.A.6 representing a quantity, V.A.7 PK4 composing/decomposing a whole, and V.B.1 joining newly arriving objects. Do not auto-credit them from a comparison. There is no official PK3.V.A.7 outcome and this family does not invent one. For PK3.V.A.8 there is a published official PK3 standard, so unlike prior unpaired Social Studies cases PK3 receives a separate graded developmental path.

Prerequisites before comparative speech and assessment provenance

Child can attend to and distinguish two bounded collections, recognize which items belong to each collection, and with prompting pair one-to-one or count small items. If these prerequisites are not available, first teach simple matching and two-set ownership as responsive foundation, then resume source comparison. No rigid age gate or learning disability inference. Each actual stage has ENTRY before MODEL, teacher MODEL on different objects/numerical pairs, active learner DURING practice including repairs, a truly unfamiliar EXIT mini-probe before content cues, and REVISIT on a genuinely later actual date with different materials. No child/educator observations or later visits have occurred.

Evidence code: U = source comparison and appropriate relation independently originated by child; A = access-only help (nonsuggestive narration, home-language interpretation, AAC, tactile orientation or motor proxy following child's chosen relational decision); H = helper gave conceptual answer, relative set direction or which set has more; X = assistance or who answered uncertain. Describe first observation in neutral language and independently record set sizes, direction, label chosen, whether actual set boundaries clear, false-cue avoidance, help provenance and context. “H” can show instructional progress but not fresh independent EXIT. Never award full source based on a choral answer; do not infer actual child results from synthetic Python tests.

PK3 graded progression — size range 0–5, genuine source A.8

PK3 C3-1 — two distinct groups, matched versus unmatched (first 1–3)

ENTRY: On a novel table mat offer two large safe objects in the first bounded space and one different in the second; ask “Do these groups have the same number? Or does one have more?” Observe the first child-origin comparative word/point/communication. MODEL on a completely different case: adult puts two wide cloth patches across from two flat wooden tiles, pairs each patch to a tile and says “Each one has a partner: same number.” DURING: learner matches first group objects to second (child does own pairing/directs proxy), notices an unmatched original item and says/points “this group has more than that group” with clear referent. Misconception/correction: says longer spaced row has more despite one-to-one match; teacher uses another unrelated 2-v-2 pair and demonstrates pairing, then a fresh 2-v-1 probe. Fresh stage EXIT: a different 3-v-2 set with changed positions and colors, first child-owned relational expression. Formal count numerals not mandatory.

PK3 C3-2 — compare up to five, direction and “less than”

ENTRY: Four large paper squares versus three large flat foam disks in distinct boundaries; neutral question “Which has more? Which has fewer/less?” No teacher hand hovering target. MODEL: on unrelated two versus three large washable toy stamps, pair objects and say “The stamp group has one fewer than the other; the other has one more.” DURING: child works two versus four, five versus three, five versus four, child can explain unmatched leftovers. Reverse left/right and referent; “this side” changes but mathematical relation persists. Repair: child chants “five” but does not identify relation; adult models on another 1-v-2 pair and invites comparison of two novel labeled sets. Fresh EXIT: 5 versus 4 arranged counterintuitively, child identifies more and less as directional relationships. Do not require written inequalities.

PK3 C3-3 — equal amounts despite different appearances; zero/one contrasts

ENTRY: Three tiny-looking but actually large safe paper discs loosely spaced versus three larger drawn discs packed closely (same three); ask what comparison amounts show. MODEL: four small-looking safe cards in a tall column versus four broad large tokens in short rows; align them one-to-one, say “Both have four, so same number even if one looks longer.” DURING: child aligns new 2-v-2 and 5-v-5 sets in different shapes, sees count unchanged; optionally explores empty 0 versus 2 and empty 0 versus 0 (distinguish blank tray from token). Repair: child picks visually larger area as “more”; educator contrasts size from count in separate demo then offers unfamiliar equal-size check. Fresh EXIT: new 4-v-4 different spatial rows plus new 0-v-3 if ready, child supplies appropriate equal / more / less relation. Zero is enrichment within upper-bounded source, not independent number-writing goal.

PK3 C3-4 — independent comparison in novel contexts and later actual revisit

ENTRY: New generic puppet collection story of three safe paper shapes and five different shapes; ask child to determine which group relative to the other is more or less. MODEL/DURING: on distinct unrelated teacher-only pairs, show alignment evidence and practice a new 5-v-5 equal case with different arrangements. Independent full-source EXIT: withheld new 2-v-5, 4-v-3 reversed order and 5-v-5 deliberately misleading layout. Child expresses appropriate more, less and same number relationships (may respond twice to single pair to show reverse) using child-selected communication, no content cues. Novel child comparison across sets up to five is a source action candidate, never verified mastery. REVISIT: only at actual different date, different newly sourced objects/pairs; current state NOT_OBSERVED.

PK4 graded progression — renew foundation then extend to ten

PK4 C4-1 — independently retrieve PK3 relational foundation 0–5

ENTRY: new 3-v-4 original picture-object sets with swapped sides and equal 4-v-4 alternate arrangement; note if child compares both sets. MODEL: on different 2-v-3 original shapes show one-to-one match + opposite-language perspective: “These have fewer; those have more.” DURING: learner makes and checks 5-v-4, 5-v-5 and 4-v-3, without equating spatial length with quantity. Repair: points at “the bigger blue paper” instead of set count; adult explicitly models “size of objects differs from how many” on unrelated scene, child retries novel. Stage EXIT: unmodeled small-range two comparisons, one more/fewer, one equal. This is prerequisite, not full PK4.

PK4 C4-2 — extend to six through eight with ten-frame or matching

ENTRY: original six versus seven safe large tokens, arranged with longer 6-row; ask which has more/fewer and what supports answer. MODEL: unrelated seven versus eight, adult pairs/ten-frame counts both and notes one unmatched item in eight. DURING: child compares 6-v-8, 7-v-6 and 8-v-8 with different arrangements, can use touch-matching, five-anchors, cardinality or row pairing, explains/shows referent. Repair: takes ten-frame capacity as count even when only six occupied; teacher demonstrates on different frame the empty slots are not objects and offers new independent pair. Fresh stage EXIT: novel 8-v-7 with longer seven-row; child gives directional relation, U or A only if first own content.

PK4 C4-3 — compare nine and ten, close pairs, equal layouts

ENTRY: nine actual large paper counters on a structured frame versus ten in scattered grouping, ask which set has fewer/more relative to other. MODEL: different six-versus-nine actual original tokens; teacher matches/counts correctly and emphasizes every item, not height/size. DURING: learner compares 9-v-10, 10-v-8, and 9-v-9 in unequal visual layouts; independently generates one equality example up to ten. Repair: learner sees 10-grid outline and reports ten even with nine filled cells; teacher explicitly shows empty slot versus item on separate example then changes stimulus to new nine-versus-ten. Fresh stage EXIT: 10-v-9 with balanced visual spacing and 9-v-9 changed grouping, learner supplies both direction and equality. Do not require numeral symbol `>` to count source language.

PK4 C4-4 — relative language, direction reversal, misleading perceptual cues

ENTRY: new 7-v-9 different object sizes and positions, ask two open questions: “Which set has more?” then “Which has fewer?” MODEL: different 4-v-6 blue/red items, adult demonstrates that A has more than B ↔ B has fewer than A and that same amount is symmetric even if row lengths differ. DURING: child creates 8-v-6 longer sparse six-row, then fixes row spacing/positions without adding pieces; asks if count relation changes (no). Reverses which set is named first, uses “equal/same,” “less/fewer,” “greater/more” in home-language/AAC as appropriate without requiring every synonym. Repair: “the red line is longer so more” counterexample by aligning one-to-one on unrelated set; fresh stage EXIT unfamiliar 10-v-7 counterintuitive layout and equal 6-v-6 differing grouping. Note that changing positions does not change quantities.

PK4 C4-5 — transfer across full published range and later actual date

ENTRY: child's first independent choice of more/fewer/equal for new set pairs including 0–5 reminder and 6–10 actual groups; do not present source answer with color or position. MODEL/DURING: teach on different source pair if needed; child chooses matching, counts, or creation route; teacher treats H as supported practice. Independent full-range-intended EXIT: several withheld genuinely new contextual examples, e.g., 4-v-4 differently shaped, 7-v-10 with shorter dense ten-row, 10-v-9 direction reversal, 0-v-2 (optional). Child compares both sets in words/symbols/AAC and can identify more, less/fewer, equal with at least one new 6–10 pair; reason may be counting, direct matching or object pairs. This is source-action evidence, not statistical proof across all 0–10 pairs. REVISIT on an actually different observed date with new objects, varying side and size; NOT_OBSERVED now.

Three genuinely different instructional mechanisms (all stages each)

  1. Method 01 — One-to-One Partner Laboratory [TEACHER_GUIDE.md]: child physically makes pairs across two distinct sets and identifies remaining unmatched objects; grounded quantitative correspondence, not color/shape illusion or rote recount.
  2. Method 02 — Layout Illusion Investigator [LESSON_02_LAYOUT_ILLUSIONS.md]: child confronts physically conserved and misleading layouts, rearranges without adding/removing to disconfirm “longer line means more”; perceptual conflict and evidence reasoning, not a matching worksheet.
  3. Method 03 — Build the Comparison and Repair [LESSON_03_BUILD_AND_REPAIR.md]: child constructs target more/fewer/equal group relationships and tests a second person's claim or creates a counterexample, demonstrating flexible relational language and direction; not replaying teacher-solved pairs.

Written four-mode route contract, not equivalent-effectiveness claim

SOLO — NOT IMPLEMENTED: future fully child-operated tablet with narrated pre-reader instructions, large independently selectable/movable pieces, fully accessible set orientation, self-controlled pairing/rearranging/building, meaning-aware hints on unrelated objects, corrective feedback for size/spacing/equality/direction confusions, novel unmodeled per-stage EXIT and real later-date REVISIT. PK3 first ≤5; PK4 retrieves ≤5 before up to ten. Software must not give away answer by longer row or buttons whose position never changes. No functional SOLO implementation or efficacy data exists. CO-PLAY: adult and child alternate comparing different pairs and explaining why; adult models unrelated demo, child constructs own comparison, can challenge inaccurate adult guesses. PK3 small groups, PK4 larger near-ties. Adult isn't allowed to choose child’s answer in scored exit; H documented. ADULT-LED ONE CHILD: teacher first probes, models on separate pair, invites genuine child-origin decision with matching/spacing/building materials, follows misconceptions and gives new probe. Short responsive sessions, individual access, U/H/A/X and real dated revisit. Does not force pencil/English speech. TEACHER-LED CLASSROOM: distribute safe original non-food large pieces, run three distinct learning stations, adult shows different demo on projector but records individual student comparisons in independent private novel scenarios. Shared chorus is NOT proof each child can distinguish quantity. Rotate observation appointments; children not assessed remain NOT_OBSERVED.

Safety/access and evidence honesty: no beans, coins, small seeds, tiny detachable pieces, food/allergen prompts or compulsory physical grasp; use stable large nontoxic objects, high-contrast/tactile mats, orientation cues, audio descriptions that report set membership without asserting which is more, home-language/sign/AAC with comparable relation categories, child-directed motor proxy, flexible processing time, individualized IEP/IFSP/504 decisions with responsible educators. Avoid child diagnosis. Individual first-source comparisons U/A/H/X are documented, never implied by printable completion. All written modes are design only; no child data, educator approval, equal-mode outcomes, actual later-date revisits or implemented SOLO.

Learning-differences stage differentiation — 2026-11-01

Compare numbers of objects in two sets and communicate directional more/fewer/equal. Do not mistake a longer row, bigger item, adult prepaired objects, familiar color or remembered numeral symbol for learner-owned comparative reasoning. Physical pairing is one valid teaching strategy, not an additional required assessment algorithm. Tactile/sign/AAC/home-language comparisons count only when the CHILD determines the numerical relation, with valid A/B referents and independent response. When access to two sets cannot be established, record NOT_OBSERVED and seek a specialist-supported alternative rather than labeling a child deficient.

PK3 C3-1 Begin two groups with 1–2 pieces, make individual pairings accessible and teacher-model on different objects; fade adult pairing. New tiny A/B groups, child shows which has more/fewer or same, naming both group referents without adult left/right answer cue.
PK3 C3-2 Offer 2–3 piece groups and child selected tactile matching; scaffold same/one leftover, then remove pairing prompts. Fresh matched and one-unmatched arrangements, independently explain or indicate A relative to B.
PK3 C3-3 Introduce varied 3–5 unequal groups with equal/unequal spacing and child-controlled count path; fade teacher attention to longest row. New up-to-five A/B groups with changed spacing, learner correctly chooses relational direction, not picture length.
PK3 C3-4 Mix more/fewer/equal within up-to-five sets, reverse physical positions after modeling on OTHER groups, fade reminders that direction switches. Unmodeled novel two-set more, fewer and same cases including five, with a real later-date revisit; score each relational first response.
PK4 C4-1 Revisit 1–5 comparatives on accessible matching mats; remove teacher location and word order cues before baseline. New 1–5 A/B groups with meaningful reversible comparison, not assumed from PK4 age.
PK4 C4-2 Teach 6–8 using child-controlled one-to-one matching and optional two-column trays; fade pre-paired model and color differences. New 7-versus-8 or 6-versus-7 group layout with no highlighted remainder; child states relative amount.
PK4 C4-3 Challenge long sparse versus short dense rows with 8–10 objects on visually/tactually accessible separated mats; teach invariance then fade warnings. New misleading spatial arrangement through ten, child compares NUMBER after rearrangement, not row extent.
PK4 C4-4 Contrast equal unlike collections and reversed direction with 9/10 near-ties; fade explicit teacher more/less synonym prompts. Unfamiliar equal and 9-versus-10 sets; learner communicates same or which group greater and which fewer.
PK4 C4-5 Vary objects, sides, spacing and relational languages across 1–10; retain access accommodation but not adult selection of relation. Fresh mixed up-to-ten more/fewer/equal comparisons including near-tie, and actual later-day different materials.

Method-specific checks: In physical one-to-one pairing, proxy hand follows precisely the child-selected pair. In layout illusions, changing spacing must not change quantity, and the exit changes the actual relation as well as the row shape to avoid fixed-answer recognition. In build-and-repair, child decides group amounts and which set changes; an adult-provided pair of totals or copying larger-group labels is HELPED. SOLO still not implemented; future audio/AAC interface must not visually cue the right relation. Written CLASSROOM rotations must observe the individual, never infer that all pupils understood from one chorus.
