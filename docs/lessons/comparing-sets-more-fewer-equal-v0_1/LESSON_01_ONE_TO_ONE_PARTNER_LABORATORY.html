Lesson 01 — One-to-One Partner Laboratory: matched partners, unmatched remainder

Original internally authored E2.2 instructional draft · 2026-10-30. Follow DEVELOPMENTAL_SEQUENCE.md as the binding developmental ladder. PK3.V.A.8 compares two sets of objects up to FIVE using comparative language, source SHA 779846ea0d4de0ae83ba66c391b769a1083f33ff90d75227c90c87579cdb0dc4. PK4.V.A.8 compares sets up to TEN with greater/more, fewer/less and equal/same, SHA ab5cf662752a22227509b99cd865d127d47388832931ce4c76867b8aad3b61af. Distinct mechanism: the child intentionally constructs one-to-one correspondence between two separately bounded collections, observes unmatched objects or equal pairing, expresses a quantitative relation with clear referents, and changes the direction of the comparison. Unlike a visual rearrangement challenge or child-created amounts, the diagnostic operation is pairing actual individual objects.

Safe original materials and preparation

Use first-party two-column wide alignment mat (original `ORIGINAL_STAGE_CARDS.html`), large flat nontoxic paper/foam cards that cannot be swallowed, tactile distinguishable left/right collection boundaries, large safe objects of differing shapes and optional audio/raised markers. For PK3 keep actual set counts at or below 5 each; introduce 1–3 first. For PK4 verify both counts ≤10; a larger group may fill a 10-cell pairing grid but the capacity is not a third counted set. No beans, button batteries, actual coins, seeds, food, sharp tools or unattended small parts. Prepare three different collections for baseline ENTRY, adult-only MODEL and hidden new EXIT; don't copy a color/position pattern into EXIT. Label cards “collection A” and “collection B” neutrally to make relational direction explicit; do not put `more` next to the right side before a child's answer. A child can align using eye gaze, signed location requests or child-directed motor proxy.

PK3 teaching: four genuinely progressive stages

PK3 C3-1 (1–3, match evidence) — ENTRY 2 big circle cards vs 1 toy-square card: “Does each thing have a partner on the other side? What has more, or are they same number?” Wait for independent first response; if child cannot yet decide group boundaries, teach two different colored mats first without grading. MODEL on an unrelated 2 matching 2 example with cloth patch and wide wooden block, educator says “I give each one a partner. No one is left; they have the same number.” DURING child selects which item pairs with which, then finds lone unpaired card in a NEW 3-v-2 practice. Adult can model separately if child lines all up without matching. Fresh EXIT two blue boats vs three red toy houses, child pairs (or directs partner formation) and says which collection has more than the other; a pointing gesture needs explicit relation choice/AAC option, not a guess based on adult gaze.

PK3 C3-2 (2–5, reversible more/less) — ENTRY 4 big paper stars vs 3 large triangles, unpaired extra must be noticed. MODEL different 2-v-3 mixed safe pieces; says “These have fewer than those because a pair is missing here.” DURING learner pairs 5 versus 3 and 4 versus 5, sees child-chosen position reversal doesn't change which set has more, and states the converse fewer relation for the other collection. Correction: if child calls the left set more simply because left repeatedly won, educator crosses positions of a different known pair, rematches, and asks new unmodeled target. Fresh EXIT five safe shapes in shorter dense line versus four in long row, child reports what has more and what has fewer independently.

PK3 C3-3 (equal despite mixed shapes, spacing, zero) — ENTRY present 3 large wide patches vs 3 physically bigger but equally countable cards spread apart; child pairs and uses “same number.” MODEL 4-v-4 on different tokens, educator shows all matched even though shapes differ. DURING learner matches different 2-v-2, 5-v-5 and optionally zero empty mat vs zero empty mat, recognizing tray outline is not a counted object. Include 0-v-2 if ready, but zero alone never satisfies general source. Repair: child says bigger object means more objects; adult slowly matches different unequal-size objects one-to-one, then fresh equal 4-v-4. Fresh EXIT novel same-number four-v-four with random card dimensions; first child-origin equality communication.

PK3 C3-4 (novel full range transfer) — ENTRY previously withheld entirely fresh original 4-v-2, count/match with no help. MODEL/DURING only on unrelated 1-v-3 and 3-v-3 contexts; learner can choose pairing order. EXIT adult offers three unseen comparison pairs 2-v-5, 4-v-3 and 5-v-5 in alternating layout, child communicates a relative more/fewer/same relationship for each and can reverse which set has fewer. This uses the whole published up-to-5 range without requiring every ordered pair. REVISIT different actual calendar date with new accurate counts/context; currently NOT_OBSERVED.

PK4 extension: five developmental stages and real quantitative referents

PK4 C4-1 (revisit ≤5): adult ENTRY 4-v-3 and 4-v-4 fresh, checks independent comparison language. MODEL unrelated 2-v-3 paired tokens, including inverse fewer. DURING child demonstrates matching and equality, not merely “the blue color”; EXIT changed orientation 5-v-4 and 3-v-3. If skill missing, return to C3-style foundation but PK4 still remains the real official grade track.

PK4 C4-2 (6–8): ENTRY six cards in stretched row against seven densely packed. MODEL seven unrelated art shapes vs eight, explain extra unmatched eighth. DURING child directs partner matching 6-v-8, 8-v-7 and 8-v-8, counts or points to remainder without counting blank grid squares. If the app or adult uses a strip with 10 empty slots, distinguish filled cells from slots. EXIT new 8-v-7 pairing with fresh icons and swapped positions, independently name more and fewer.

PK4 C4-3 (9–10 and equality): ENTRY nine large leaf cards vs ten large rectangles, ask which has more than other. MODEL 6-v-9 on totally separate story, demonstrate matching. DURING child pairs 9-v-10, 10-v-8, 9-v-9 (different shapes and spacing). Adult resists forcing word “greater” if child accurately communicates “more.” EXIT new 10-v-9 and novel 9-v-9 grouping, observe two distinct relations.

PK4 C4-4 (direction, misleading extent): ENTRY 7-v-9 where seven are huge cards spread long, nine are compact cards in short line. MODEL different 4-v-6 paired cloth squares, explicitly tell “A has more than B / B has fewer than A,” not which side will be correct on EXIT. DURING child rotates/reorders arrays and rematches; older child may use count totals as another reliable strategy, not mandated formal symbol. EXIT 10-v-7 with longer seven-row then equal 6-v-6 randomly spaced, independent relational communication for correct collection and equality.

PK4 C4-5 (novel complete range and real return): ENTRY varied new small 4-v-4 and large 8-v-10. MODEL and supported practice on different pairs only. Independent EXIT fresh 4-v-4, 7-v-10 and 10-v-9, with changed positions, demanding child-origin comparison of both sets and understanding more/fewer/equal in home language/AAC or other accessible communication. This is not a 0–10 exhaustive every-pair exam or mastered-standard label. REVISIT at real later date with novel pairs in new context, no one observed now.

A complete five-phase teaching script with what teacher does

ENTRY before teaching: For the lesson's prepared baseline, present genuinely unfamiliar groups of two and three real safe pieces: “Here is one collection and another. You may explore these. Are they the same number? If not, which has more than the other?” Do not name the correct side or pair the items for the child. Record the actual counts of both shown groups, child-first relation with direction and any child-origin pairing/counting. A different mathematically valid stage-specific uncoached pair (e.g., PK3 initial two versus one or extra three versus four) is a legitimate option only if its actual set counts and first response are recorded as that distinct observation, not silently substituted for planned 2-v-3. If child asks “What is a group?” start with group boundaries as prerequisite, no source-credit guess.

MODEL different set sizes: educator shows two cloth patches and two foam rectangles, demonstrates pairing one-to-one: “This one has a partner. This one has a partner. None is left. Both have the same number.” Then model three opposite four with extra; never reuse scored numeric pair and layout. Keep adult demonstration visible as teaching, not as evidence of child's first independent source response.

DURING child chooses pairing approach and can change which group is on which side; teacher asks “Do the partners run out? Which group is extra?” Correction 1: if child responds “bigger paper”, change to unrelated pair and teach item count versus size then new challenge. Correction 2: if child announces a total but not comparison, use two new collections and ask a relational question. Correction 3: if motor proxy hand aligns them, record access-only A if child chose matches; if teacher tells child which group is larger, H. Optional child-chosen meaningful question: Invite the learner to choose a safe pairing purpose—for example, whether every large toy figure has one pretend seat, or whether each child-selected art shape has a matching storage mat. They arrange two actual previously unpaired collections, choose partners one at a time or independently compare both counts, then explain which group has more, fewer or the same and what the leftovers mean. Do not choose set sizes, partner matches or the correct relation for them. This is supported practice, never a substitute for unseen independent EXIT; an equally valid quiet plain-block comparison needs no pretend story. The learner's genuine original pairing/question drives next practice rather than predetermined sticker answer.

EXIT reserve new pair of physical pieces at the grade limit (≤5 or ≤10), unseen before any teaching. Child independently pairs or counts, points to/reports correct more than, fewer than and new equal comparison as a relation between two explicitly identified sets. Do not count an adult's choral word or guessing left as U; an accurate count of a single set is necessary but not sufficient for comparison. Re-probing with same cards after correction is DURING not fresh EXIT.

REVISIT actual different calendar date: teacher schedules independent unfamiliar paired comparisons, records child origin U/H/A/X and access, not merely “revisit planned.” No child has been observed in this authoring checkpoint.

Four fully written modes, equivalent intended concept but not proven equal performance

SOLO — NOT IMPLEMENTED: future prereader-operated tablet names two separate collections through child-controlled narration, lets learner drag each actual large independent virtual item to the opposite group's matching slot or use switch/eye-gaze/AAC pairing; learner selects a relation using audio symbols with actual grammatical referents (“Group A has fewer than Group B”), receives meaning-specific coaching on different examples if pairing or size confusion occurs, then completes concealed novel exit and later-date review. PK3 introduces 1–3 then up to 5, PK4 reviews 5 then goes 6–10 and near-ties. No adult must supply the missing teaching, but this remains a written specification with NO app implementation or child tests.

CO-PLAY: adult offers original physical tokens, child chooses first collection and creates partners; adult demonstrates on unrelated tokens and later makes a deliberately wrong claim (“these bigger tokens are more even though there's fewer”), giving child chance to challenge. PK3 groups ≤5 and PK4 groups ≤10, including equal sets; child and adult both contribute but only child-origin comparison is graded. Parent may use home language and no forced handwriting.

ADULT-LED ONE CHILD: teacher gives child safe mat and separate ENTRY objects, waits for first attempt, models a different count relationship, invites child-directed rematching of new pairs, corrects a specific misconception and reserves a new unmodeled EXIT; documents each first response, child-origin set identification, support and next teaching adjustment. For disabled grasp child guides another person with AAC; H vs A is kept separate.

TEACHER-LED CLASSROOM: make paired station with large stable pieces and durable grid, show unrelated adult modeling projected to class, then each learner has own individually accessible pair of collections with variable counts. Teacher records 2–3 focus children at a time in novel comparative opportunities, schedules others rather than assigning a choral right answer to everybody. Keep separate PK3 small groups, PK4 larger near ties, equality counterexamples. Don't force speed or public right/wrong ranking.

Access, safety, false-positive and external evidence limits

All props adult-inspected, oversized nontoxic nonfood, no small manipulatives or choking hazards. Home language, AAC/sign, contrast/tactile alignment, child-controlled audio, switch/eye gaze, adjustable positioning and extra response time; responsible educator must consult any applicable IEP/IFSP/504 with family/qualified team. Child-selected motor proxy A does not supply which side has more; adult conceptual instruction H does. false-positive: child echoes adult “red more” after adult pairs the two groups or chooses the physically biggest cards and gets comparative credit. Concrete repair: use truly different safe 2-v-3 model and new own 3-v-5 paired case with colors reversed; child must produce relation and identify referents before any content cue. Retrospective differentiated comparison audit (2026-11-01)

PK3: teach and fade, new evidence, guard bias

Teach: Use tactile or visual two-set matching with 1–5 real child-chosen item pairs; if an adult proxy physically aligns items, the child must decide BOTH members of each pair and later state relation.

Unmodeled source evidence: Novel up-to-five mismatched/equal sets with no completed matching; record child-owned pairings or other genuine comparison and A relative to B.

False credit: Adult matching every object and announcing which group is more, or child pointing to bigger-looking toys, cannot prove a numerical relation.

PK4: teach and fade, new evidence, guard bias

Teach: Pair sets of 1–5 first, then 6–10 with child-directed assistive marking and varied materials; do not make all learners count aloud or select a written sign.

Unmodeled source evidence: Fresh up-to-ten near-tie and equality cases; individually record child-origin A to B and B to A comparative meanings.

False credit: A visually longest row, prepaired answer or single count of ten is not an independently communicated greater/fewer/equal comparison.

Four written modes: SOLO (unbuilt) requires accessible narrated or signed A/B orientation, independent unhighlighted relational choices and actual child-owned paired/set evidence rather than a visually obvious answer button. CO-PLAY may let the parent provide objects and offer learner-chosen motor assistance, but not announce which set is greater. ADULT-LED can teach pairing on separate examples then remove numerical hints for new EXIT. CLASSROOM must record individual first comparative relations, not group chorus or finished arrangements made by peers; later true-date checks must be genuinely observed. Respect real relevant individualized plans, sensory preferences and qualified professional input. Access-only aid, mathematical help and not observed are distinct; learning support is not a disability diagnosis.

Lesson 01 independent mechanism and differentiation check

This lesson teaches why one set has more: child gives or directs each real item one partner from the other set, sees unmatched pieces or none, then communicates which bounded collection has more/fewer/same. Keep pairing a voluntary learner strategy, not a new compulsory official test. PK3.V.A.8 uses up-to-FIVE objects PER set, PK4.V.A.8 up-to-TEN; an exact chant or handed-over partner pairs cannot substitute for an independent numerical relation. Separate material banks: For the planned uncoached ENTRY prepare a genuinely unfamiliar two-versus-three set pair with large safe neutral pieces. Keep separate adult MODEL two-versus-two and two-versus-four groups with no copied source answers. DURING uses unshown child-chosen three-versus-four and four-versus-four groups. For independent EXIT use fresh, child-unseen, unpaired collections: PK3 five-versus-four and three-versus-three, or PK4 nine-versus-ten and eight-versus-eight. The same familiar accessible type of large safe item may be used again when actual counts/layouts are new and the adult has not supplied quantity, partner matches or relation; varying object types is an optional transfer opportunity. At a genuinely later-date REVISIT, prepare different unknown counts/layouts and permit the same safe accessible object type when appropriate. These example pairs are educational probes rather than mandated exhaustive pairs. Blank mat regions, empty grid slots and tray outlines are never counted as objects. Misconception-specific feedback: If child says the physically longer row has more, on another adult set move counters closer without adding/removing and pair them; then invite learner to choose own pairs on fresh DURING set. If child counts 5 and 4 but never compares, ask “Five in which group? Four in which? Which has more than which?” during practice, not during fresh EXIT. If child points to a pre-colored answer label, remove it; replace with neutral group identifiers, and sample new unmodeled arrays. EXIT source split: PK3.V.A.8 requires original comparative LANGUAGE about two new sets with each <=5; PK4.V.A.8 requires original comparative LANGUAGE about two new sets each <=10, including genuinely accessible larger examples. Semantically composed sign/AAC/home-language count as communication, not teacher-written options. Record U/H/A/X, direction and exact first child expression, and don't claim one correctly guessed direction proves all relation categories. Companion Facilitator Guide 01 — One-to-One Partner Laboratory

Pair: Lesson 01. Sources: PK3.V.A.8 / PK4.V.A.8. This adult companion is not a counted lesson; source criteria and progression are in objective educator guide.

How correspondence teaches this specific mechanism

An independently selected partner for every item makes equality concrete: no leftovers means same quantity; a leftover on side A means A has more than B. The adult must not prearrange correspondences or supply the relational sentence. The child may compare by another defensible count strategy at EXIT; partner drawing is not a mandated extra attainment criterion. PK3 children compare within five per group; PK4 extends above five up to ten per group.

Practical preflight

Prepare first independent ENTRY two-versus-three on an original safe large set pair. The adult MODEL uses a separate two-versus-two matching pair and two-versus-four contrast, never the exact child's source bank. Fresh DURING pairs include PK3 three-versus-four and four-versus-four or PK4 six-versus-seven and seven-versus-seven. Independent EXIT shows truly new, unpaired, unknown PK3 five-versus-four and three-versus-three or PK4 nine-versus-ten and eight-versus-eight, with no disclosed answer or completed matching. Safely reuse a familiar accessible item type if its actual layout/count has not been seen; a different material type can broaden transfer but is not a source-validity requirement. At later actual REVISIT use new unknown amounts/layouts, with material type flexible for a child's access. For sensory access use accurately described raised/contrast objects, not printed “answer” color. Bound sets visibly without leading labels. Record source ID, each set quantity, first child-origin directed comparative language, actual pairing/matching if done, prompting U/H/A/X and date. No tiny counters or real food.

Adult interaction and fading decisions

ENTRY: “Look at collection A and collection B. Is there the same number? If not, which has more than the other?” Observe first child strategy without demonstrating on this bank. Correct response must identify a relation, not say an unattached “five.” MODEL: On adult-only distinct objects, physically create one-to-one partners and narrate “Everyone has a partner; they have the same number,” then “This side has one without a partner, so it has MORE than that side.” Demonstrate a converse fewer relation when appropriate. Remove model. DURING: Let child place or direct each pair on new real pieces; ask “Who still needs a partner?” If child compares row length, spread apart another practice set, rematch without adding tokens, and let learner re-evaluate. If child has counted only one group, ask for two group referents. Fade teacher pointing, prefilled matching lanes, hinted words and adult-selected partner targets. EXIT: Give entirely unseen physical pair(s). PK3.V.A.8: independently compare two sets each ≤5 using meaningful referent-specific comparative LANGUAGE; PK4.V.A.8: compare sets with accessible near-ties/equality through ≤10 using self-origin comparative language. A trained proxy can move child-specified items as A, but adult-supplied count or relational label is H. A guessed side or “bigger toy” criterion is not independent quantity comparison. REVISIT: At a genuinely different calendar date, another novel set and independent original relation. Record NOT_OBSERVED until actual observation.

Diagnostic feedback ladder

If “longer is more,” teach distance is not a new item on an unrelated teacher bank, then let child pair own new practice set. If says “same” because both are blue, vary color while preserving number; ask for reliable pairs. If child cannot identify collection boundaries, reduce set size and mark only the two collections, then fade boundary cues—not place answers. If reluctant to grip, use child-directed switch/gaze or neutral proxy without assuming equivalence to independently placing items. If child says true “B fewer than A,” accept it even if adult expected “A more than B”; reverse referents only to clarify, not to manufacture a false error.

Seven differentiated needs and four routes

Attention/executive: predictable one-pair-at-a-time routine, fade count tracks; language/communication: meaningful child-authored home language/AAC/sign relation; literacy/phonology: labels read by adult as access, no print demand; numeracy: accessible tactile real one-to-one scaffold, gradual fade; autism/sensory: clean low-texture alternative and quiet predictable bank; intellectual/developmental: begin 1–3 pairs, then untaught larger EXIT at appropriate stage only; motor/hearing/vision: oversized high-contrast/raised shapes, neutral child-directed proxy, accurate quantity descriptions with team review, not answer-coded prompts. SOLO — NOT IMPLEMENTED: future accessible digital item-pairing and comparative response must let child originate all decisions and survive an uncued new EXIT. CO-PLAY: caregiver can physically handle learner-directed pieces, not pair on child's behalf. ADULT-LED: individual preflight for numerical versus visual access and H/A separation. CLASSROOM: teacher models one unrelated set; privately score each learner's own new two-group comparison, not peers' or chorus. No real child outcome, physical field QA, independently approved accessibility, completed later REVISIT or validated mode parity.
