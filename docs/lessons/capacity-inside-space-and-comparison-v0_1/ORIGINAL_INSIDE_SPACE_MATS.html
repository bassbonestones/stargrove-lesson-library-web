02 · Empty does NOT mean no space

EMPTY – SAME INTERIOR BOUNDARY

There can be room inside even when the box holds nothing right now.

PARTLY FILLED – SAME INTERIOR

Already contains safe big pieces, but the walls have not changed.

Separate “how much is here NOW” from “how much COULD fit inside.” Use actual clean dry containers and large safe blocks, not these drawings, for a genuine physical investigation.
